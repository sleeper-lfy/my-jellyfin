# 安卓 VR180 播放

桌面首页、侧栏、导入类型与安卓导航栏已加入“VR电影”分类（API 类型 `vr`）。安卓打开该分类的影片时自动启用 VR180；打开电影、电视剧或其他分类时恢复普通模式。也可以在播放页点击“VR”临时切换。已有普通电影可在桌面海报墙右键“移至VR电影”，文件位置、收藏、评分、观看进度不变；无需重新导入。桌面端此分类用于管理，VR 投影播放在安卓端实现。默认输入为 **180°、左右 3D（左半左眼、右半右眼）、标准等距柱状投影**。普通视频默认保持普通模式，不自动误判为 VR。

- 标准模式：每只眼对应完整的 180° 等距柱状图。
- 鱼眼模式：每只眼一个居中圆形、180° 等距鱼眼图，使用 GPU 投影；不是简单拉伸。裁切、非居中镜头或不同鱼眼标定的素材可能不匹配。
- 单屏预览显示左眼；“双眼观看”将两眼分别投射到屏幕两半，支持交换左右眼。
- 触摸拖动转向；有游戏旋转向量传感器时可使用陀螺仪转向（水平／俯仰）。设置中可复位朝向、调整 50°–110° 视场角，默认 90°。
- 双眼模式自动隐藏主要控制栏；右上角“控制”按钮可恢复操作，系统返回手势仍可退出。
- 音频通过 LibVLC 立体声输出，保留音轨选择及系统音量控制；视频 3D 布局与音频声道独立。
- 普通／VR 模式切换保留播放位置及观看记录。后台暂停并释放解码器；前台恢复。VR 设置保存，启用状态不跨影片会话自动打开。

解码继续使用 LibVLC 3.7.7，优先硬件解码，失败时软件重试；视频帧经 SurfaceTexture 交给 OpenGL ES 2 着色器投影，不在 CPU 搬运逐帧像素。仍通过已有局域网认证流和进度同步接口播放。

此版本提供手机屏幕的 VR180 观看，不包含 OpenXR 头显设备运行时、位置追踪、镜片专属畸变标定或空间音频。安卓编译、静态检查和投影数值测试不能代替真机验证：安装后需用已知左右眼测试片检查两种投影、上下方向、陀螺仪、横竖屏切换与返回恢复。
