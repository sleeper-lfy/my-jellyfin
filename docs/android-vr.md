# 安卓 VR180 播放

桌面首页、侧栏、导入类型与安卓导航栏已加入“VR电影”分类（API 类型 `vr`）。安卓打开该分类的影片时自动启用 VR180；打开电影、电视剧或其他分类时恢复普通模式。也可以在播放页点击“VR”临时切换。已有普通电影可在桌面海报墙右键“移至VR电影”，文件位置、收藏、评分、观看进度不变；无需重新导入。桌面端此分类用于管理，VR 投影播放在安卓端实现。默认输入为 **180°、左右 3D（左半左眼、右半右眼）、标准等距柱状投影**。普通视频默认保持普通模式，不自动误判为 VR。

- 标准模式：每只眼对应完整的 180° 等距柱状图。
- 鱼眼模式：每只眼一个居中圆形、180° 等距鱼眼图，使用 GPU 投影；不是简单拉伸。裁切、非居中镜头或不同鱼眼标定的素材可能不匹配。
- 单屏预览显示左眼；“双眼观看”将两眼分别投射到屏幕两半，支持交换左右眼。
- 默认单指横滑调节进度，双指捏合缩放；在 VR 设置关闭“单指横滑调进度”后可触摸拖动转向；有游戏旋转向量传感器时可使用陀螺仪转向（水平／俯仰）。点击“回正”以当前头部朝向为中心，同时清除拖动偏移；“播放设置 → VR 设置 → 恢复初始位置及默认缩放”同时复位朝向和 90° 视场角。视场角 50°–110°：角度越小画面越近；按钮每次调整 5°，不是改变视频分辨率。VR 单屏与双眼均使用横屏。
- 播放控制浮在视频上方，不压缩画面。单击画面显示／隐藏控制栏，播放时 4.5 秒无操作自动隐藏；刘海、挖孔与系统导航区留出安全距离。VR 底部可直接回正、拉远、拉近和切换标准／鱼眼；双指捏合也可缩放。
- 音频通过 LibVLC 立体声输出，保留音轨选择及系统音量控制；视频 3D 布局与音频声道独立。
- 普通／VR 模式切换保留播放位置及观看记录。后台暂停并释放解码器；前台恢复。VR 设置保存，启用状态不跨影片会话自动打开。

解码继续使用 LibVLC 3.7.7，优先硬件解码，失败时软件重试；视频帧经 SurfaceTexture 交给 OpenGL ES 2 着色器投影，不在 CPU 搬运逐帧像素。仍通过已有局域网认证流和进度同步接口播放。

此版本提供手机屏幕的 VR180 观看，不包含 OpenXR 头显设备运行时、位置追踪、镜片专属畸变标定或空间音频。安卓编译、静态检查和投影数值测试不能代替真机验证：安装后需用已知左右眼测试片检查两种投影、上下方向、陀螺仪、横竖屏切换与返回恢复。

## 蓝牙遥控器、耳机与手柄（Android 0.4.1）

先在 Android 系统设置中配对设备，进入播放页的 **设置 → 蓝牙 / 手柄映射**。选择功能后按一次设备按键，或推动摇杆／按下扳机，即可学习绑定。支持播放／暂停、独立播放或暂停、前后 10 秒、切换投影、拉近／拉远、回正、恢复初始视角及显示／隐藏控制栏；也可绑定“不执行操作”屏蔽某键。一个按键对应一个功能，重新绑定会替换旧功能；查看已保存的映射或恢复默认均在此菜单中。

| 默认输入 | 操作 |
| --- | --- |
| 方向左／右、L1／R1、媒体快退／快进 | 回退／快进 10 秒 |
| 媒体上一首／下一首（0.4.5） | 上个视频／下个视频；电视剧切集，VR 可切换文件与作品 |
| 中键、Enter、空格、A、耳机播放暂停键 | 播放／暂停 |
| 方向上／下、L2／R2、摇杆上下 | 拉近／拉远（仅 VR） |
| X / Y | 标准与鱼眼切换 / 回正（仅 VR） |
| Start / B | 恢复初始视角及 90° 缩放 / 显示隐藏控制栏 |

HID 按键按 Android 的设备描述符分别保存；系统 AVRCP 媒体按键使用通用映射。摇杆支持左右摇杆、方向轴和左右扳机，设有死区及回中阈值；跳转和缩放可长按，投影切换与播放暂停每次按下仅触发一次。普通播放中 VR 专用动作不生效。默认音量键继续控制系统媒体音量；只有主动绑定后才改为相应动作。返回、主页、电源等系统保留键不可绑定。切到后台、失去焦点时停止手柄长按动作，后台不接管媒体控制。

此接入使用 Android 的 HID 输入事件和 MediaSession/AVRCP；设备需向系统提供这些标准事件。仅使用厂商私有 BLE/GATT 协议的遥控器需要另外适配。耳机通常只有少量按键；自定义映射不能使设备产生其本身没有的独立按键。按键学习、MediaSession 路由和布局有自动化测试，实体蓝牙设备及佩戴头显仍需真机确认。

0.4.4 修复了横屏俯仰串入水平转向，增加按视频保存的灵敏度、平滑时间及上下反转设置；蓝牙映射增加独立的上一集 / 下一集。已有用户映射不覆盖。详见 [当前修复与验证范围](pc-stability-and-updates.md)。旧 0.4.3 安装包不包含这批更改。

## 0.4.5 大幅抬头与视频切换

接近垂直抬头时不再用视线的水平分量求方位，改为基于回正姿态的完整四元数转向；数值回归覆盖抬头至 120°、越过 90°、回落、两种横屏、近垂直转头与回正。显示俯仰仍限制在 ±85°，避免投影翻转。实际传感器表现需在手机上验证。

单击视频显示控制栏，播放 / 暂停两侧可直接操作上一 / 下个视频（竖线加三角形图标，长按显示提示）。蓝牙“下个视频 / 下一集”和“上个视频 / 上一集”调用相同逻辑，原有映射保留。同一作品先切换相邻文件，电视剧止于本剧首末集；VR 等其他分类可继续当前浏览 / 筛选范围的相邻作品，随机队列则按队列切换。向前切换作品使用其继续观看文件，向后进入上一作品的最后一个文件。切换作品后按分类自动应用普通 / VR 模式。
