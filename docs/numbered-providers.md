# 编号影片来源与备用来源

媒体管理 → **分类规则与来源 → 安装与检测影片来源** 打开来源窗口。随应用提供 `javbus-films` 和 `javdb-films` 两个影片元数据插件，与原有 `*-actors` 头像插件相互独立。

## 安装与配置

选择来源后点击“安装 / 更新并启用”，界面会先列出完整网络主机权限，用户确认后才更新并启用。只允许更新应用随附的这两个指定插件；保留已有代理、优先级和其他插件设置，不自动更新第三方插件。

返回“分类规则与来源”，选择电影或 VR 分类，设置首选来源，在备用列表勾选来源并用上移 / 下移调整顺序。此页同时展示整理目标和命名模板，核对后保存该分类默认规则。安装新来源后可点击重新读取配置。新入库任务复制当时的备用列表，先尝试导入或目录规则指定的首选插件；搜索失败、无唯一匹配或详情校验失败时继续尝试备用来源。最多支持一个首选和七个备用来源。

如果所有来源都无法唯一匹配，保留原文件并进入待确认；保留候选的同时记录对应来源，不能把不同站点的候选混在同一次确认里。网络或解析错误在没有可确认候选时保留现有自动重试策略。只有已启用、支持影片搜索的来源可被使用，禁用和未安装的来源会记录原因，不会由自动流程自行启用。

## 来源检测

JavBus / JavDB 搜索或详情返回 403 时, 使用来源窗口新增的“站点访问设置”检查请求模式与站点会话。自动模式使用按需的浏览器兼容请求; 验证页、登录要求、拒绝访问和限流分别提示。操作与验证边界见 [站点访问与 403](site-access.md)。

在窗口底部输入一个已知影片编号，再点击“检测来源”。检测实际执行编号搜索与匹配详情解析，不合并任何影片或下载图片：

- “可用”：编号唯一匹配，且详情来源 ID 与编号校验通过。
- “站点已响应，但此编号无唯一匹配”：请求及解析结束，但不能确认该编号的影片；不把它当作刮削成功。
- “检测失败”：网络失败、验证页、未识别页面结构、来源未启用等。

结果包含检查时间、耗时和原因，保存在本地 `source-health:<插件ID>` 设置中。检测结果只代表当时该编号的请求，不保证未来所有请求都成功。

## 资料与边界

两个插件仅输出来源实际提供的标题、编号、日期、简介、标签、演员、导演、制作方、海报和剧照，不返回磁力、种子或视频下载链接。没有的资料留空。JavDB 的内部影片 ID 是不透明标识，匹配使用单独的 `external_ids.product_code`，不会将站点 ID 误当作影片编号。VR 使用普通电影来源时仍保留 VR 分类，已有锁定和 NFO 保护规则不变。

请求沿用宿主的精确域名、代理、预算、TLS 和响应大小限制。网站验证页和无法识别的 HTML 会报告错误，不尝试绕过交互验证。图片如果指向清单外域名，宿主仍会拒绝，不会动态扩大权限。

本次验证使用 `tests/fixtures/numbered_sources/` 中**明确标注为合成、内容虚构的 HTML 结构样本**、真实 JS 沙箱执行和模拟网络故障。当前云环境没有对这些真实站点进行在线验收。网站改版、地区限制或验证策略可能需要更新解析器或由用户配置可用的应用代理；没有声称所有真实编号均已验证。
