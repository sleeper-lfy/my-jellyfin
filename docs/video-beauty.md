# 实时视频美颜（PC / Android）

在播放器“播放设置 → 实时美颜”开启。PC 的开关位于播放设置内，Android 使用同名菜单。默认关闭，磨皮与肤色提亮各为 0–100，按当前视频记忆；服务端升级到 0.4.12 后两端通过已有播放偏好接口同步。旧服务端不接受新参数时，手机仍在本机保存。

滤镜使用本项目的共享 GLSL 实现：肤色范围估计、保边双边平滑以及有限度提亮。没有接入 GPUPixel 或人脸模型，不包含瘦脸、大眼、身份识别或 AI 修复。肤色估计会受灯光和原片调色影响，也可能处理与皮肤相似的背景颜色。算法代码位于 `src/lumen/shaders/beauty-core.glsl`，Android 使用相同内容的资源文件；测试检查二者一致。

视频在本机 GPU 渲染时处理，原视频不变，也不上传画面。PC 需要 libmpv，Qt 兼容模式会禁用美颜。PC 的锐化与美颜可分别开关。Android 开启普通视频美颜时从 VLC 直接显示切到 OES 纹理渲染，保留播放位置及暂停状态，第一次开关可能短暂重新缓冲；之后调强度不重启解码。横竖画面保持显示比例。

Android 的 VR180 标准/鱼眼、单屏/双眼复用原有投影通道，美颜取样限制在当前眼睛内，避免左右图像互相取样。参数对两眼相同，不对脸部进行独立几何变形。

遇到卡顿、发热、色彩异常时关闭。手机 GPU 初始化失败会退回普通播放并显示提示。4K/8K、HDR、不同设备、长时间播放和 VR 双眼的真实观感仍需要实机测试，自动单元测试不能代替这些检查。

正式稳定版发布沿用 [发布验收](release-acceptance.md)。未完成设备验收时，安装包只能作为明确标注验证范围的测试预发布供试用，不能填写虚假的人工通过记录。
