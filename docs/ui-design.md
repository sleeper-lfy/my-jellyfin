# UI 设计规范：Jellyfin 深色媒体库风格

用户明确要求与 Jellyfin 风格一致。本次以 Jellyfin Web 默认深色媒体库的布局与卡片规则为参考重做，保留 Lumen 产品名称。对照上游 `jellyfin-web/src/components/cardbuilder/card.scss` 的透明卡片、2:3 竖海报、16:9 横卡、图下标题、小圆角和悬停反馈；没有拷贝 Jellyfin 品牌或宣称是其官方客户端。

## 页面骨架

- 顶栏高 68px：抽屉按钮、品牌、首页/收藏、全局搜索、随机播放、设置。
- 导航抽屉宽 220px，默认收起，提供所有主分区和任务入口；选择分区后收起。
- 主内容边距 42px，背景近黑 `#101010`，正文 `#eeeeee`，辅助文字 `#999999`，交互蓝 `#00a4dc`。
- 首页以“我的媒体”横向入口开始，随后按真实数据展示继续观看、最新电影、最新电视剧、为你推荐。没有影片的分组不填假数据。
- 电影、电视剧和演员页保留可滚动海报墙；筛选、导入、智能片单等业务入口继续可用。

## 海报与交互

- 无外层蓝灰卡框，标题和年份在图下居中；图片圆角 3px。
- 竖卡绘制区约 2:3；继续观看使用 16:9 横卡。
- 悬停压暗图片并显示蓝色播放按钮。点击中间播放按钮直接播放，点击其余位置打开详情。
- 剧集数量使用右上蓝色圆形标识；观看位置使用海报底部蓝色进度条，不展示完播率统计。
- 个人评分与年份同处辅助信息区；演员仍显示个人算术均分和作品数量。
- 收藏可由顶栏直接进入；筛选和队列继续面向全部符合条件的结果。

## 详情与播放

- 详情页使用真实缓存图作为大幅背景，叠加暗色遮罩与向下渐变；左侧大海报，右侧标题、元数据、播放和个人操作。
- 图像缺失时显示中性深色背景，不造假影片海报。
- 播放器、设置、任务和统计使用相同黑灰/蓝色主题，保留已有功能。
- Qt 原生控件保留键盘焦点、输入、文件选择和系统 DPI 支持。

## 验证

离屏遍历全部页面和主要对话框，检查真实视频播放。增加首页媒体入口和顶栏收藏导航测试。默认空库截图使用真实应用渲染；测试中的合成视频仅用于独立测试目录，不进入用户默认库。Windows 实机 DPI/字体和可用性验收仍待执行。
