# 接手 Jellyfin 本地媒体库

使用新版电脑端，点击 **导入** 并选择原有电影或电视剧文件夹，选择正确分区即可。视频、NFO、海报仍留在原位置；系统读取资料并将海报副本保存至自己的缓存，不需要重新联网刮削。安卓客户端通过电脑端 API 自动看到导入结果，无需更新客户端。

已经导入过的视频：再次导入同一路径，会补读或更新 NFO，不重复创建视频记录。界面显示“NFO 更新”数量。若有警告或失败，在任务列表查看具体路径和原因。

## 目录与匹配规则

电影优先读取与视频同名的 NFO（后缀大小写不限）：

```text
电影库/
  一部电影/
    Film.mkv
    Film.nfo
    poster.jpg
```

没有同名 NFO 时，仅在当前目录只有一个视频的情况下读取 `movie.nfo`，避免把同一份资料套在不同影片上。标题相同但外部 ID 冲突时记录失败，不自动合并不同作品，原视频不受影响。

电视剧应导入包含 `tvshow.nfo` 的剧集目录或其上级媒体库：

```text
电视剧库/
  一部剧/
    tvshow.nfo
    poster.jpg
    Season 1/
      任意文件名.mkv
      任意文件名.nfo
```

`tvshow.nfo` 提供整部剧的资料；同名 `episodedetails` NFO 提供单集标题、简介、season、episode。NFO 有明确季集编号时，不要求视频文件名符合 S01E01；支持 season 0 特别篇。不会把单集标题或单集外部 ID 当成整部剧的资料。只在所选导入目录内寻找 `tvshow.nfo`，因此不要只选 Season 子目录。

## 可接收的资料

- 标题、原始标题/排序标题（作为别名）、年份、简介、首映日期。
- 类型、标签、导演、制作方、分级及演员姓名/角色；未知演员性别保持未知。
- `uniqueid` 以及常见 IMDb/TMDb/TVDb ID，用于避免跨来源重复。
- 普通 `rating` 或 `ratings/rating` 中的默认评分，按 max 归一为 0–10，标注为“本地 NFO”来源评分。
- `userrating`：仅首次创建作品时迁移整数个人评分，不用网站评分冒充个人评分。
- `watched`、`playcount`、`resume/position`：仅首次创建视频记录时恢复已看标记或继续播放位置；不会将 playcount 伪造成真实播放会话或观看时长。
- 本地 `thumb aspect="poster"` 相对路径、`视频名-poster.jpg/png`、`poster.jpg/png`、`folder.jpg/png`。海报转换为 JPEG 缓存，原图不改动。远程图片地址不自动下载；越过所选目录或指向符号链接的海报不读取。

NFO 原始 XML（含未映射字段）始终留在原目录。当前不导入 Jellyfin 数据库、账号、插件配置、收藏或完整多用户历史；Jellyfin 默认未必将用户观看历史写入 NFO，缺失的数据无法仅靠 NFO 还原。不支持 NFO 写回、完整 fanart 图片集合或所有扩展字段。

## 更新与覆盖规则

1. 本地 NFO 已提供的资料和海报优先保留，手动在线刮削只补缺失字段。
2. 带 NFO 作品跳过导入后的自动联网匹配和自动移动，先保留现有目录布局；手动整理仍按已有规则执行。
3. 重复扫描可更新 NFO 中有值的资料，缺失或空字段不清空已有资料；同时保留新系统已有个人评分、收藏、播放位置和已看标记。手动锁定的字段也不会被 NFO 覆盖；需要保留手动修改时请在“编辑资料 / 锁定”勾选对应字段。
4. 损坏、过大或包含 DTD/实体声明的 NFO 会记录警告，继续尝试按文件名导入视频。若电视剧文件名也无法提供季集，则记录该视频失败，修正 NFO 后重新扫描。

支持常见 UTF-8、带 BOM 的 UTF-16 XML。推荐先选择一个小目录验证标题、海报、评分和季集，再导入全部媒体库。不要删除原始 NFO；它仍是迁移和重新建库的数据来源。

### 导入进度与显示

导入时，窗口底部显示已处理文件数、总数、百分比与当前文件。扫描目录时显示扫描状态；计算大文件指纹时另显示该文件的读取百分比，随后显示媒体分析、缩略图生成阶段。总进度按文件数计算，并非剩余时间估算。任务记录的 `payload.progress` 保存当前阶段与文件路径。

电影 NFO 中的 `season`、`episode` 字段不参与解析，兼容旧工具写入的 `-1` 等占位值。剧集的 `-1` 季集编号回退到文件名解析，季号 `0` 仍表示特别篇。此前出现 `NFO 数值越界：season` 的电影，可在升级后重新导入同一目录：系统更新已存在文件的 NFO 资料，并保留个人评分、喜欢状态、观看进度和手工锁定字段，不需要删除媒体库。

媒体库右侧可切换“海报”和“缩略图”，选择会自动保存。海报使用本地配套图片或已有封面；缩略图优先使用视频截图，没有截图时回退到已有封面。卡片下方的星号是来源评分，“我的”是个人评分；空心／实心心形表示未喜欢／喜欢。右键卡片或使用播放器心形按钮可切换喜欢状态。

播放器使用覆盖在画面上的顶部标题栏与底部控制栏，播放时闲置会隐藏控制栏，移动鼠标即可恢复。左右快退／快进按钮和键盘 `←`／`→` 每次跳转 10 秒，在开头、结尾限位；空格暂停／继续，`F` 切换全屏，`Esc` 退出全屏。齿轮按钮打开音轨和字幕设置。

详情页海报等比例完整显示；背景优先读取同目录 `影片名-fanart.jpg/png`、`fanart.jpg/png` 或 `backdrop.jpg/png`，其次使用视频截图，没有横向图片时使用深色背景。背景仅绘制在页面上方，不会溢出到文件列表和来源评分区域。首次读取本地背景图需要重新导入目录。首页“我的媒体”卡片随宽度保持 16:9，海报行会为标题、喜欢状态和评分预留完整高度。

详情页在主窗口内打开，顶部“返回”回到原来的媒体列表与筛选状态。点击标签或演员姓名会直接显示整个本地媒体库的匹配作品；标签采用精确匹配，演员按姓名及别名匹配，不会被之前的筛选条件限制。演员墙点击姓名也直接进入筛选结果。
