# 编号影片与 VR 自动入库

本说明对应源码改动，现有安装包尚未包含。

## 配置与日常使用

1. 在媒体管理 → 分类规则与来源 → 安装与检测影片来源中安装、启用随附的影片来源，也可在设置中安装支持影片 `search` / `detail` 的其他插件。演员头像插件不能用于影片识别。电影和 VR 可分别配置首选与备用来源，详见 [编号来源](numbered-providers.md)。
2. 在分类规则与来源页，为电影、电视剧或 VR 统一保存来源顺序、整理目标和分类命名模板。目标留空保留原位置；不选刮削器而设置目标时，按现有资料整理。
3. 媒体管理 → 目录与入库，添加监控目录。选中目录打开详情可查看最终生效规则并设置覆盖，支持同分类不同目录使用不同来源。目录草稿需点击“保存目录设置”生效；含移动规则时会说明自动移动行为。
4. 程序运行时检查稳定文件，快速入库后自动识别、取完整详情、通过现有插件合并资料和缓存图片，再执行整理。窗口关闭时不运行监控；重新启动后未完成的自动入库任务继续执行。
5. 电脑任务中心 → “待确认与重试”。选中待确认任务并点击恢复 / 重试，可直接查看已保存候选封面。确认后自动继续；无候选时打开详情，可重新搜索或输入详情 URL。手机任务中心可查看状态，确认与重试仍在电脑操作。

## 匹配和恢复规则

- 支持常见字母数字编号及 FC2 / FC2-PPV 形式，统一大小写、空格、下划线和连字符。读取文件名和直接父目录中的编号，CD / PART 等分段后缀不作为影片编号。
- 编号候选必须唯一，类型必须兼容；普通电影来源可填充 VR 资料而保留 VR 分类。无编号时使用精确标题及可用年份。多个编号、多个候选或没有匹配均保留原文件待确认。
- 获取详情时再次核对来源 ID 与可用的影片编号。主来源失败时按配置尝试备用来源，全部失败不会继续自动移动。已有 NFO 字段、手工封面及锁定字段沿用插件的保护规则，允许补缺，不再因任意 NFO 字段存在而跳过整次识别。
- 网络等处理异常最多自动尝试五次，间隔递增；之后进入待确认。任务保存阶段与移动日志，重启后可继续。已完成作品不因重复手动扫描反复刮削；新增文件可再次处理。
- 文件整理沿用校验复制、拒绝覆盖与恢复日志，不新增删除规则。现有按目录归组规则不变，不按一个猜测编号自动合并两个已有本地作品。

## 当前边界

未配置命名模板时仍使用原有目录布局及原视频文件名；可在媒体管理中配置 [整理命名模板](organize-templates.md)，手动整理支持执行前预览。图片下载沿用插件缓存，失败图片可在媒体管理 → [资料修复](metadata-health.md) 中单独重试，无需重新覆盖文字资料。来源可用性取决于已启用的影片插件和实际网络，本次没有进行真实站点验收。目录监控仍需应用运行，没有新增后台系统服务。

## 按分类手动刷新目录

在电影、电视剧、VR 等页面点击“媒体目录”，或进入媒体管理的目录与入库页。窗口默认选中当前分类；同一分类可保存多个目录。添加、暂停、移除以及刮削规则编辑均针对列表选中的实际目录，点击“保存目录设置”生效。

“立即刷新当前分类”扫描该分类所有已保存目录（包含暂停自动监控的目录）；“刷新选中目录”只扫描一个目录。全部分类视图可一起扫描所有配置目录。扫描在后台执行，新增影片、新电视剧和新增季集快速入库，并加入已配置的自动刮削整理流程。修改时间距离现在不足稳定等待时间的文件暂缓入库，避免读取仍在复制的文件。

刷新会报告新增、资料更新、等待稳定、缺失、不可用目录和导入失败的数量。缺失视频先列出路径清单，确认后清理媒体库记录及其对应播放历史，不删除磁盘文件。提交时再次检查目录可读性、文件是否重新出现、文件路径是否已变化以及是否存在进行中的播放；离线、权限错误或正在播放的记录均保留。来源资料仍存在的作品可作为未入库资料保留。


## 单个视频拖入

可拖入一个或多个本地视频，也可与文件夹混合拖入。确认分类和来源后，单文件仅导入该文件，不扫描父目录的其他视频；关联 NFO、字幕与原有去重规则继续适用。失败或取消后的重试保留原文件候选范围。默认建立引用，不移动原文件；文件夹拖入继续递归扫描。
