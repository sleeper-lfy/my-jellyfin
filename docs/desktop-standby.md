# Windows 自启动与轻量托盘待机

Windows 正常启动 Lumen 后，通知区域会出现 Lumen 图标；Windows 可能把它放在任务栏的隐藏图标栏中。

- 关闭主窗口：回到托盘，已开启的手机局域网服务和目录监控继续运行。
- 双击托盘，或右键选择“打开 Lumen”：重新打开主界面。重复启动程序也会复用同一资料库的后台实例。
- 右键选择“退出 Lumen”：停止手机服务和后台调度，安全取消正在进行的任务并保存播放记录，然后退出。遇到未保存记录时仍保留原有重试／取消退出的选择。

关闭主窗口时，正在进行的 PC 播放、暂停的视频或导入任务会继续保留界面进程；这些活动结束后再释放完整界面。没有活跃播放或任务时，界面进程退出，只保留轻量托盘和服务进程。手机正在使用的 LAN 监听与视频传输不随界面关闭或重新打开而重启。

## 开机自启动

在 Windows 安装版中打开 **设置 → 通用 / 数据安全 → 开机自启动 → 登录 Windows 后在后台启动**。启动后先显示托盘，不自动打开完整主窗口。

默认不勾选。开关读取 Windows 当前用户实际注册项，开启时固定当前安装位置和资料库绝对路径，无需管理员权限。保存失败会显示提示并恢复开关状态。可在此取消；Windows 设置中的“启动应用”禁用状态仍由系统管理。源码运行与非 Windows 环境不提供该系统开关。

原地升级保留用户的启用选择；卸载只清理指向本次安装位置的 Lumen 注册项，不删除资料目录或其他安装的配置。

## 内存目标与验证边界

目标是无活跃播放、导入和下载时，后台常驻尽量控制在 **50MB 以内**。没有通过强制压缩工作集或给进程设置 50MB 硬上限来隐藏占用；扫描、提帧、图片解码和界面打开期间允许产生正常的临时内存需求。

常驻后台使用标准库和原生 Windows 托盘，不创建 QApplication，不加载播放内核或缓存整套海报。自动扫描、媒体补充、巡检和发现通过可取消的短时进程执行；LAN 图片校验与缓存也隔离到短时进程，结束后释放其 Qt 内存。PC 操作、LAN 下载及自动任务共享并发预算，播放时后台处理让步。

PyInstaller 的标准 PySide6 启动钩子原本会提前加载 QtCore；新增的专用启动钩子仅为轻量主进程跳过这一步。GUI 和需要 Qt 的工作进程仍使用标准初始化，保留插件与图片格式支持。

目前的实际源码入口在 Linux 隔离库中，启动及处理 LAN 封面后，常驻 RSS 约 **21–22 MiB**，未映射 Qt 或 libmpv；独立的自动监控／NFO 图片入库测试结束后也恢复到轻量待机。数据仅代表这些合成场景，**不是 Windows 安装版的 50MB 验收结果**，也不包含活跃界面、任务进程或任意规模资料库的峰值。

- [目录监控、NFO 图片和媒体任务内存记录](validation/background-linux-memory.json)
- [全量源码验证：962 项通过、3 项跳过，零失败](validation/desktop-standby-source.json)

## 0.4.20 Preview 3 安装版自动验收

无托盘自动验收中，安装版后台最高工作集 **37.31 MiB**（39,120,896 字节），专用提交 **21.64 MiB**；工作集低于 50,000,000 字节目标。未使用工作集压缩或硬内存限制；该结果不替代真实桌面托盘、登录启动及大资料库人工验收。
