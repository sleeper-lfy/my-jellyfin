# 插件资源下载与影视入库

以下为当前源码行为；本轮没有生成或发布新 EXE / APK，历史安装包不会自动更新。

## 默认保存位置

在 PC **设置 → 下载** 分别设置电影、电视剧和 VR 电影的默认目录。未配置时先采用该分类已设置的整理目录，否则使用用户 Videos 下的 `Lumen/Movies`、`Lumen/TV Shows`、`Lumen/VR Movies`。每部作品创建“标题 (年份)”子目录。

详情页显示实际保存位置。点击 **更改本片下载目录** 可保存该作品的目录偏好，后续点击下载直接使用它；**恢复分类默认目录** 清除单片覆盖。Android 详情显示的是**电脑上的保存位置**，可以填写电脑端的绝对路径更改。两端下载进入同一媒体库。

下载设置界面：[截图（独立测试环境）](screenshots/next-download-settings.png)。

## HTTP / HTTPS 直链

点击资源后，Lumen 使用插件的域名权限和代理流式下载，显示字节进度，不把整部视频读入内存。优先采用响应中的 `Content-Disposition` 文件名，否则使用视频 URL 的文件名；无扩展名的接口根据响应类型生成视频文件名。多个不透明接口按 URL 区分名称。目标存在时停止，不覆盖已有视频。

下载写入 `.part` 临时文件，成功才发布最终视频；取消或传输失败清理临时文件。完成后验证本地视频并直接关联当前作品，保留当前标题、年份、演员、标签、海报、剧照、来源、个人评分与收藏，立即更新详情中的视频列表。传输时同时计算 SHA-256，入库不再完整读取视频计算哈希。

作品目录会补充 `movie.nfo` 或 `tvshow.nfo`、已有海报和 `extrafanart` 剧照；能从文件名识别季集时，同时写入视频同名的单集 NFO。原有 NFO 和图片不覆盖。无法识别的电视剧视频保留在当前剧集中，季集显示待补充，不自动猜测编号。影片可立即播放。

仅接受实际视频文件；网页、压缩包、种子文件和 HLS 播放列表不是直链视频下载。插件应提供最终 HTTP 视频地址，重定向不自动跟随。文件已保存但验证 / 入库失败时会保留文件并记录原因，可修正后点击 **检查下载文件并入库**，无需重复下载。

## 磁力与外部下载器

设置支持自动寻找 qBittorrent、指定 qBittorrent 程序、系统关联下载器，以及自定义程序和参数。qBittorrent 使用官方支持的参数传入磁力与保存位置：

```text
qbittorrent --save-path=<作品目录> --skip-dialog=true <magnet链接>
```

参数以独立进程参数传递，不经命令行 shell。依据：[qBittorrent 官方命令行参数定义](https://github.com/qbittorrent/qBittorrent/blob/master/src/app/cmdoptions.cpp)。

系统 `magnet:` 通用协议不携带保存目录，无法保证迅雷等关联工具使用 Lumen 的目录。选择系统关联模式时会明确提示，并在 PC 复制目录路径，需在下载器内选择该目录。支持目录参数的其他工具可以在自定义模式中配置 JSON 参数数组，必须同时包含 `{url}` 和 `{directory}`；具体参数需以该工具文档为准。

外部下载不在 Lumen 内显示伪造的进度或“完成”状态。等待下载器完成后，点击 **检查下载文件并入库**：只检查当前作品的下载目录，将视频关联当前作品，保留影视信息，重复文件不重复入库。磁力多文件电视剧可一次检查多个季集。请在外部下载器完成后执行，避免把尚未下载完整的视频当成已完成文件。

## 局域网 API

所有接口继续要求 Bearer 密钥。

| 方法与路径 | 用途 |
| --- | --- |
| GET `/api/works/{id}` | 返回 `download_directory`，用于显示电脑端保存位置 |
| POST `/api/works/{id}/download-directory` | `{ "directory": "电脑绝对路径" }`；空字符串恢复分类默认目录 |
| POST `/api/works/{id}/downloads` | `{ "index": 0 }`，使用已保存插件资源的下标，202 返回 `task_id` |
| GET `/api/downloads/{task_id}` | 排队、下载字节、入库、完成或失败状态 |
| POST `/api/works/{id}/import-downloads` | 检查外部下载，202 返回 `task_id` |

服务端后台下载队列有数量限制；同一资源不会重复排队。提交后固定所选目录，资源列表变化时停止并要求刷新，避免下载另一条资源。客户端离开页面不终止电脑下载；关闭电脑服务会请求停止在途任务。
