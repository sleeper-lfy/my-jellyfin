# 页面导航与返回

PC 顶部导航与侧栏均提供「首页」「为我推荐」「影片发现」一级入口。Android 的一级导航同样包含这三个入口。「为我推荐」读取本地可播放媒体的推荐结果；「影片发现」读取插件已经发现的影视资料，包括尚未下载的内容，可继续进入详情查看剧照与下载资源。

在详情里点击标签或演员会打开相应筛选结果；返回按钮返回实际来源页面。例如：影片详情 → 标签结果 → 另一部影片详情 → 演员结果，逐次返回会依次回到另一部影片详情、标签结果、原影片详情，再回到最初媒体库。主动点击一级导航会开始新的浏览路径。

PC 保存筛选条件、页签、搜索词、已显示项目数量、列表与详情滚动位置；普通详情返回保留原列表控件和选中项。历史最多保存 30 个数据快照，不保留隐藏详情页面。目录读取与推荐计算默认始终在工作线程运行，小型媒体库也不例外。筛选面板会立即打开，下拉选项在后台读取；用户可以先输入条件，后台结果不会覆盖输入中的文字。

Android 保存同样的搜索和分类条件，返回详情时恢复原滚动位置；返回原媒体库时按原已加载页数在后台恢复列表。元数据跳转历史最多保留 20 个数据快照，不缓存整棵页面视图。

推荐页和发现页内搜索、应用筛选时保留各自页面。发现详情中的标签或演员筛选继续包含未入库资料；来源页面原有的页签、筛选和滚动位置仍可返回。推荐页按推荐顺序排列，不显示与推荐顺序冲突的普通排序控件。

局域网接口 `GET /api/discover` 与普通媒体库接口使用相同鉴权、筛选、排序与分页参数，仅返回拥有插件来源的资料，不要求已经有本地视频文件。`GET /api/filters?discover=true` 可读取发现资料的筛选选项。
