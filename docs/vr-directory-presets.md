# VR 目录播放预设

在电脑端“媒体管理 → 目录与入库”中选中 VR 目录，打开“VR 目录播放预设”。可配置现有 Android VR180 左右 3D 播放器支持的参数：标准等距柱状 / 鱼眼投影、单屏左眼预览 / 双眼观看、左右眼交换、陀螺仪、横滑调进度、视场角、初始朝向、灵敏度和平滑。表单可滚动，保存和取消固定在底部。

预设只改变播放设置，不处理或转换视频，不新增 VR360 / 上下 3D 解码能力，也不改变作品的电影 / VR 分类。普通影片仍按普通模式打开；切到 VR 模式后使用这些参数。目录名不用于猜测影片格式。

## 生效顺序

1. 单片手工保存的参数优先。
2. 没有单片覆盖的参数采用包含此文件的最具体目录预设。
3. 没有目录值的参数沿用手机播放器默认值。

子目录预设独立于父目录，选择更具体的那一份，不累积父目录的配置。新加入视频不需要另外套用；读取播放设置时动态计算。更改目录预设会在下次打开视频时作用于没有单片覆盖的参数。

“移除此目录预设”保留所有单片设置。手机 VR 设置中的“恢复目录 VR 预设（清除本片覆盖）”只清除当前视频的 VR 覆盖，保留字幕与美颜设置。目录预设未设置时不显示这一按钮。

## 存储与接口

目录规则位于设置 `vr_directory_presets`，不批量复制到 `playback_preferences`。`preferences()` 返回的 `vr` 是有效值；有目录预设时另带只读 `_vr_inherited` 参数字典，不包含本机路径。保存 `vr` 字典只更新显式字段，`vr: null` 清除当前视频 VR 覆盖。

Android 修改某个 VR 参数时只上传改变的键，修改字幕不会把整份目录预设固定到当前影片。旧客户端原样回传 `_vr_inherited` 时，服务器忽略只读标记，并跳过与真实目录默认值相同且没有原有单片覆盖的字段。

## 验证

覆盖嵌套目录优先、邻近同名前缀不匹配、新视频继承、修改默认值、单片覆盖、恢复继承、无效路径 / 参数、数据库重开、鉴权 LAN 接口和编辑对话框。Android 差量上传、旧服务器兼容以及既有媒体工具测试通过编译和 Robolectric 测试；没有进行头显或手机真机验收。
