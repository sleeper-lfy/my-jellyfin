# Android 0.4.15 与 PC 首页调整

按已确认的深色青色设计和播放器 V2 实现。截图来自实际 Qt / Android View；示例库、影片、图片和观看记录仅用于验证，不进入用户资料库。

## 页面与共用组件

- 首页、媒体库、发现、详情、我的、连接、更新、电脑遥控、电脑任务与应用内网页工具栏共用近黑蓝背景、两级浮层、青色主操作、圆角输入框及线性图标。默认编辑框通过主题统一，已有操作、鉴权和数据范围保持不变。
- 底部导航明确使用独立横向布局，四项等分；分类、计数、排序和列表菜单保持在工具区。海报网格根据实际测量宽度重排并重新计算 2∶3 图片高度，避免分屏时使用整块屏幕尺寸。
- 我的页面按影片、播放设备、应用设置分组；使用带图标的左对齐入口，保留收藏、想看、片单、统计、队列、遥控、任务、连接和更新。
- 继续观看独立显示标题、续播文件／季集、已看／总时长和剩余时间；长文件身份可展开，未知时长明确说明。缺图用统一占位，实际图片仍由已有缓存和下载队列加载。
- 筛选使用观看状态分段、个人偏好组合和并排年份。多标签、包含任一、排除类型与评分收进高级条件，已有条件自动展开。重置只清空草稿；取消保留原条件；条件同步到页面恢复、智能片单和相同范围的随机队列。

## 播放器

竖屏使用视频为主体、右侧轻量操作、底部影片信息和进度的布局。横向片源保持原比例；横屏使用居中播放、前后跳转及上下个视频的控制。VR 的回正、缩放和投影独立展示；低高度窗口从设置进入低频选项。

单击视频空白区域切换控制层，按钮与进度条不参与该手势。按用户后续要求，此动作优先于原型中的单击暂停；播放／暂停由控制层的播放按钮完成。PC 使用相同的单击语义，手动隐藏不会被鼠标移动立即唤回；自动隐藏仍可通过鼠标移动唤回。

Android 普通视频播放时按住约 400ms，临时请求 2×，显示速度提示并收起控制层。松手恢复原先实际选定的速度；不降低本已高于 2× 的速度，不写入固定倍速设置。横向拖动、第二指、取消、失焦、外部暂停、缓冲、停止／更换解码器及生命周期退出均清理临时状态。VR 保留独立手势，不启用此长按。

设置分为常用、画面、高级。音轨、字幕、速度、自动下一集、文件选择、书签、评价、手机队列均可访问；解码与诊断从高级进入。原画直传不等于转码，“硬件优先”不代表已确认实际硬解。

## PC 新增项

首页“我的媒体”放在继续观看之前，卡片宽度读取与续播相同的缩略图尺寸设置，图片按同一宽高比例展示，放不下自动换行。修改缩略图尺寸后分类卡片也重新排版。

作品、首页媒体行和集数菜单可在系统文件夹中定位视频。多文件作品明确选择文件；Windows Explorer 选中文件，macOS 使用定位，Linux 打开父目录。调用通过结构化参数或本地文件 URL，不拼接 shell。文件已离线时提示错误，不打开其他目录。

## 验证范围

原生 Android 回归覆盖窄屏、大字号、横竖屏／安全区、四项导航、海报重排、续播身份与时间、筛选草稿与状态恢复、控制层切换、临时倍速原速恢复和取消。截图为实际 View 的原生绘制；播放器截图未连接真实视频，不作为解码与性能证据。

PC 验证覆盖首页排序与换行、相同卡片宽度、视频空白点击、自动／手动隐藏并存、文件定位参数、离线／多文件取消，以及标签排除和队列范围。最终 Windows 安装与卸载、Android 签名和发布证据随 Release 提供。

小米 15 真实 HEVC 4K 播放、长按速率切换后的音画同步、系统文件管理器选择和所有实际设备组合仍需实机确认。
