# 影片管理与播放工具

以下入口对应当前源码，安装包需重新构建后才包含。

| 功能 | 入口 | 行为 |
| --- | --- | --- |
| 编号影片来源 | 媒体管理 → 分类规则与来源 → 安装与检测影片来源 | 安装与检测来源；首选、备用顺序及整理目标在分类规则页统一配置 |
| 缺失资料修复 | 媒体管理 → 资料修复 | 按分类检查，显示选中或全部影片数量，只补空字段；图片可单独重试 |
| VR目录预设 | 媒体管理 → 目录与入库 → 选择 VR 目录 → VR目录播放预设 | 子目录优先，单片手动设置优先；Android播放设置可恢复目录预设 |
| 整理模板 | 影片详情 → 更多操作 → 文件与版本 → 整理文件；媒体管理 → 分类规则与来源 / 目录详情 | 配置分类默认或目标目录模板；先预览再执行，字幕、NFO及其本地图片配套处理 |
| 版本对比 | 影片详情 → 更多操作 → 文件与版本 → 版本对比 / 默认播放 | 查看真实分辨率、编码、音轨、字幕、时长和大小，设置默认或打开目录 |
| 重复候选 | 媒体管理 → 整理与版本 | 按编号/已有完整指纹列候选，进入对比；不会自动删除视频 |
| NFO导出 | 详情 → 更多操作 → 资料与图片；列表多选操作条；媒体管理 → 导入导出 | 分别针对当前影片、已选影片或明确的分类；默认跳过已有文件，选择更新时先备份 |
| 续播首页 | PC / Android 首页 → 继续观看 | 按最近播放排序，明确当前视频、进度、剩余时间和电视剧下一集 |

编号影片插件 JavBus / JavDB 尚未在真实站点完成在线验收；页面变化、站点验证和网络环境可能影响抓取。管理窗口的检测功能会实际请求来源并显示结果。目录 VR 预设复用现有 Android VR180 左右3D播放能力。

手工标签、演员、NFO和锁定字段在资料补缺时保留。编号相同也可能是分段或不同版本；重复候选不会自动合并或删除。版本窗口“仅移出选中版本”保留磁盘文件，下次目录扫描可能重新入库。
