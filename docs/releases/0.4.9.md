# Lumen 0.4.9 · 播放中评分，喜欢即收藏

按用户确认的规则，PC 和 Android 播放器统一为三个入口：

- **评分**：直接选择 1–10 分或清除个人评分。
- **喜欢／收藏**：同一个按钮、同一份状态，重复点击取消；选中后取消“不喜欢”。
- **不喜欢**：与喜欢／收藏互斥，重复点击恢复中立。

无需退出播放器。普通播放、全屏、手机横竖屏和 VR 均可使用；保存不重载视频、不改变当前集、进度或播放会话。电视剧各集共用作品级评分与偏好。手机在后台保存，失败提示重试；保存期间切换作品仍写入原作品。

旧收藏和评分保留。0.4.8 的独立喜欢合并到收藏，不再显示独立按钮；旧数据若同时收藏且不喜欢，保留负反馈。兼容旧 API 的 `liked` 字段作为收藏别名，不重复计算推荐权重。旧备份在副本上迁移，原备份不修改。推荐参考偏好，随机播放仍保持等概率。
