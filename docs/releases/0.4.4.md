# Lumen 0.4.4 · Windows + Android

本版修复导入进度导致布局抖动、重复导入与添加媒体弹窗阻塞、全屏切换重建播放器，以及时间点书签入口和保存时间。减少海报与剧照解码、后台任务闭包等内存占用。

Android 新增 GitHub 更新检查、下载及安装前完整性与签名验证；修正 VR 横屏陀螺仪俯仰串入水平转向，增加灵敏度、平滑和上下反转设置；蓝牙支持独立映射上一集 / 下一集。已有用户映射保留。

包含 0.4.3 的目录增量监控、播放诊断、字幕调节、截图书签、每视频 VR 设置记忆、手机遥控电脑、媒体库体检和后台队列管理。没有新增 GPU 增强算法、安卓离线观看或 2D VR 功能。

## 下载

- [Windows x64 安装包 Lumen-Setup-x64.exe](https://github.com/sleeper-lfy/my-jellyfin/releases/download/v0.4.4/Lumen-Setup-x64.exe)：Windows 10/11 x64，包含 libmpv 与 FFmpeg。
- [Android 安装包 Lumen-android-debug.apk](https://github.com/sleeper-lfy/my-jellyfin/releases/download/v0.4.4/Lumen-android-debug.apk)：Android 8.0+，versionCode 7，保持上一版签名，可覆盖安装。

Release 同时提供两个安装包的 SHA-256 文件。仓库 [target](../../target/README.md) 也保存 APK 及 Windows 校验分片；完整 Release EXE 无需合并。

## 验证范围

发布流程先在 Windows 运行测试、构建并验证安装、程序启动及卸载，再验证 APK 与源码树及签名一致后统一发布。实际结果以 [Release 状态](../../target/release-status.json) 和 [公开下载校验](../../target/release-download-verification.json) 为准。

本地源码验证：Python 185 项通过、1 项依赖 Windows 的测试跳过；原生 libmpv 嵌入单独通过。Android 46 项测试及 lint 通过。功能入口、截图与内存对比见 [稳定性与更新修复](../pc-stability-and-updates.md)。真实 Windows 任务栏、多款手机陀螺仪与蓝牙控制仍需硬件验收。
