# Lumen 0.4.14 Preview 4

Windows 10/11 x64 与 Android 8.0+ 测试预发布。真机音频、DPI、升级恢复和真实刮削站点验收尚未完成；不替换稳定最新版。

Preview 4 新增：

- 内置 Javinizer-Go 番号刮削引擎：在“设置 → 按需刮削引擎”下载组件并启用（SHA-256 校验，也可手动选择官方 v1.6.6 组件）；按番号依次查询 R18.dev / LibreDMM / JavBus（可选 JavDB、Jav321、FC2），来源失败冷却并自动回退，资料缓存在本机 SQLite；仅用于电影与 VR 电影，组件只在查询时运行。
- 番号引擎与 JavSP 本地引擎、JavBus / JavDb 数字源插件共存：媒体管理的分类默认来源、目录规则、导入窗口和详情刮削均可按媒体类型选择引擎，番号引擎只出现在电影与 VR 分类。
- 更新检测增强：Gitee API 未返回附件大小时改从下载响应解析；允许 foruda.gitee.com 附件 CDN 重定向。
- 手动刮削与资料合并支持取消；DMM 图床请求自动附带 Referer，避免图片下载被拒。

Preview 3 修复：

- 任务运行中关闭：界面及时关闭，取消请求、保存进度并退出进程；整理复制支持取消与恢复。
- 批量导入后的刮削限定本批作品，完整处理超过 10 部的批次，不处理无关旧任务。
- 分类 / 文件夹内搜索保留当前范围。
- 首页“我的媒体”卡片放大，窄窗口自动换行。
- 后台任务和列表读取期间仍可拖入目录，连续拖入追加批量清单；保留演员头像拖放。
- 电视剧详情增加明显的选中集、整季及特别篇管理入口；记录移除与永久文件删除分别确认，保留其他季集及共享附属文件。

包含此前 Preview 1 的功能：

- 自动入库：编号识别、首选及备用刮削来源、补图、整理、失败重试和待确认任务；按分类管理监听目录与手动同步。
- 当前影片可直接新增、编辑和删除标签与演员。
- 统一媒体管理：来源检测、资料修复、整理命名模板、VR 目录预设、重复候选、版本对比、NFO 与图片导出。
- 电脑端分组侧栏与详情菜单，Android 首页／媒体库／发现／我的四个导航；修复窄屏、大字号、年份输入及横屏 VR 控件重叠。
- 修正智能片单排序、续播筛选和随机播放的当前列表范围；手机可查看电脑任务。
- 图片请求独立排队，重复下载合并、可见图片优先，离开页面取消旧请求；后台资源限流，播放期间自动任务在安全点让步。

两个安装包必须由同一标签源码重新构建。Windows 完成自动测试及安装、启动、mpv 运行库、插件 worker、卸载验证；Android 完成测试、lint、签名、版本及 ZIP 对齐验证后才发布。验收 JSON 与 SHA-256 随安装包提供，人工项目保持未验证。

Android versionCode 为 21，使用此前 0.4.12 测试预发布的持久签名；签名不同的旧安装不能覆盖安装。Windows 首次使用若缺少 FFmpeg，将引导配置本机版本或下载已锁定校验和的组件。

本次发布在 GitHub Releases；当前应用的 Gitee 自动更新渠道需要另外同步后才能检测到该版本。
