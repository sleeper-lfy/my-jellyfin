# Lumen 0.4.16 Preview 2

Windows 10/11 x64 与 Android 8.0+ 测试预发布。Android versionCode 32，沿用既有签名，可覆盖安装。保留个人资料与播放偏好。

- Android 继续观看使用当前续播文件的缩略图，不再复用作品海报；无缓存时由电脑按该视频生成缩略图。缩略图缺失不回退海报，生成失败显示占位。
- 继续观看缩略图和媒体海报均完整显示，按比例留边，不强制裁剪主体。续播按钮与图片分开，避免遮挡画面。
- 统一页面、操作行和弹窗的间距与触控尺寸。发现标签输入与应用分行，标题栏、排序、更多和队列操作保持间距；窄屏不挤压输入内容。
- 手机播放队列的长标题最多显示两行并省略，列表可滚动，播放、排序和移除操作保持可见。
- 修复离开图片页面时，取消活跃下载释放工作线程、可能抢先启动待取消图片的竞争；先清理队列，再断开活跃连接。
- 减少 LibVLC 时间／位置事件中的重复 UI 更新与几何测量。普通视频继续使用 SurfaceView；保留单击显示／隐藏控件和长按临时倍速。
- 增加 MediaCodec 兼容解码选择，可保留位置切换并恢复自动策略。选择硬件优先不代表内核已确认实际使用硬解。
- 播放诊断区分真实视频传输与 LibVLC 计数，新增缓冲、拖动恢复和帧增量信息。首个速度采样显示采样中；无数据读取并不自动判定为网络故障。

此版本包含可复现的布局与播放刷新问题修复；小米 15 上 HEVC 4K 持续播放、拖动恢复与音画同步仍需真机验证，不以自动测试代替实际播放结果。测试预发布需从发布页手动安装。
