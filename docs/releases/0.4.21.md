# Lumen 0.4.21 Preview 1

Windows 10/11 x64 与 Android 8.0+ 测试预发布，标签 `v0.4.21-preview.1`。Android versionCode 40，保留 ARM32＋ARM64 通用包及原签名。

- 修复 Android 详情收藏／想看／评分图标与文字对齐，状态刷新保持竖向布局。
- 修复“我的”数量与说明、连接列表名称和地址的对齐及内边距。
- 媒体库筛选改为官方 Material 3 BottomSheetDialog、Filter Chip 和固定操作栏；下拉采用官方 OutlinedBox 输入，保留组合筛选、验证、片单与接口。
- 原生深浅主题语义颜色与 Compose 一致，生产界面继续深色。处理键盘安全区及 Android 8 兼容性。其余旧弹窗尚未整体迁移。
- 手机和 PC 更新渠道可点击打开 GitHub Releases；识别到明确候选版本时打开对应版本页面。

[实际界面与修改范围](https://github.com/sleeper-lfy/my-jellyfin/blob/v0.4.21-preview.1/docs/android-ui-alignment.md)。Windows 自启动、托盘与后台服务沿用 0.4.20 行为。4K HEVC 流畅度和实际手机键盘仍需真机确认。

两端完整测试、Windows 实际安装／卸载及 Android 持久签名校验通过后才公开附件；公开附件包含安装包、SHA-256 与验收记录。
