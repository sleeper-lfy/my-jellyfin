# Lumen 0.4.20 Preview 3

Windows 10/11 x64 与 Android 8.0+ 测试预发布。Android 版本 `0.4.20`、versionCode `39`，标签 `v0.4.20-preview.3`；APK 沿用既有证书，保持 ARM32＋ARM64 通用兼容。

## PC 自启动与托盘待机

- 设置 → 通用 / 数据安全新增“登录 Windows 后在后台启动”，默认关闭，使用当前用户注册项，不需要管理员权限；自启动后先在托盘待机。
- 关闭主窗口进入通知区域，手机局域网服务和目录监控继续运行；双击托盘重新打开，右键“退出 Lumen”才完全停止。正在进行的 PC 播放、暂停或导入继续保留，空闲后释放完整界面。
- 常驻服务与 Qt 界面分进程运行；自动扫描、媒体分析、发现和图片处理使用可取消的短时进程，任务结束后释放内存。PC 操作与 LAN 下载共享任务预算，播放时后台处理让步。
- 保留安全退出、最后播放记录保存、取消退出、后台任务取消及升级等待全部应用进程退出的流程。安装／卸载仅管理本次安装的自启动项。
- 为 Windows 安装版新增实际后台入口、LAN、图片／任务进程、退出与内存测量验收。内存目标为无活跃播放和任务时尽量低于 50MB，结果见 `windows-acceptance.json` 的 `automated.installation.standby`；无交互验收不代表真实桌面托盘或开机登录已人工验证。

## Android 修复

- 修复系统浅色模式下进入发现页后界面变白；生产页面与系统栏沿用应用深色主题，详情返回和页面重建保持一致。
- 长按临时倍速不再显示动态文字浮层；保留 400ms 触发、临时 2×、松手恢复原速，以及取消、暂停和失焦后的恢复。
- 支持文件管理器等其他应用通过“打开方式”选择 Lumen 播放视频；支持已授予读取权限的本地视频和 HTTP／HTTPS 视频链接，无需先连接电脑。外部播放不写入媒体库观看记录、队列或个人状态，媒体库专属操作不可用。

本版保留原 LibVLC 内核、海报／续播缩略图规则及已有 UI；未加入此前讨论但尚未实施的 ARM64 独立包或 R8 裁剪。小米 15 的 HEVC 4K 流畅度、真实来源应用授权和外部文件跳转仍需真机确认。

## 验证与安装

标签源码执行 Windows 全量测试、构建、实际安装／卸载、mpv 与插件工作进程验收，以及 Android 全量测试、lint、持久签名、版本和 ZIP 对齐校验。两端全部成功后才公开附件。Release 提供 Windows 安装包、Android APK、SHA-256 和对应验收记录。

[托盘操作与内存说明](https://github.com/sleeper-lfy/my-jellyfin/blob/v0.4.20-preview.3/docs/desktop-standby.md) · [Android 实际界面截图](https://github.com/sleeper-lfy/my-jellyfin/blob/v0.4.20-preview.3/docs/android-actions-0.4.19.md)。测试预发布需要手动安装，人工验收项目保持独立记录。


Preview 1 的 Windows 测试发现测试环境适配问题：生成的临时安装／数据路径超过自启动命令的 260 字符限制，以及源码测试使用的 Windows 虚拟环境 Python 启动器产生了额外 PID。已缩短测试夹具路径并为源码集成测试使用直接解释器入口；保留实际注册命令长度保护和安装版进程身份校验。使用新标签完整重建，不覆盖旧标签，不跳过失败测试。

Preview 2 的 Windows 994 项中 993 项通过，唯一失败为后台正常退出后，本机闭合端口返回连接超时而非连接被拒绝。Windows 退出验收改用系统 TCP 监听表，要求 LAN 与控制端口均已消失，系统调用失败、异常数据或仍存在监听均判失败；保留进程退出与运行时文件清理检查。新标签先经 Windows 专项预检再完整构建，保留前两次失败标签和发布门禁。
