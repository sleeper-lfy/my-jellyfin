# 0.4.3 安装包（未发布 Release）

此次交付按用户要求直接打包已有功能，不增加新的 GPU 增强算法。Windows 和 Android 的应用源码为 `91f07502e6afd58a46375082f9f487ab15e51eb9`，功能与 `2910b67` 一致，仅更新版本及打包配置。

包含目录增量监控、播放诊断、按视频保存字幕设置、时间书签与截图、Android 每视频 VR 设置记忆、手机遥控电脑、只读媒体库体检，以及可暂停 / 取消 / 重试的后台队列。入口、截图和限制见 [媒体工具说明](../media-tools.md)。没有安卓离线观看和 2D VR 观看。

## 获取安装包

- Android：[target 中的 APK](../../target/Lumen-android-debug.apk)，版本 0.4.3 / versionCode 6，Android 8.0+。签名与 0.4.2 相同，可覆盖安装。
- Windows：[target 目录](../../target/README.md) 提供校验分片，下载所有 `Lumen-Setup-x64.exe.part*`、`windows-installer.json` 与 `Prepare-Installer.ps1` 后运行该脚本，合并得到完整 EXE。也可在 [打包运行](https://github.com/sleeper-lfy/my-jellyfin/actions/runs/39930617864) 的 `Lumen-windows-x64` Artifact 中获取完整安装器，下载 Artifacts 通常需要登录 GitHub。

安装前请以 `target/package-status.json` 的构建及交付状态、`windows-installer.json` 和 `android-build.json` 的源码提交及 SHA-256 为准。0.4.2 的历史 Release 不随此次打包更新。

Android 构建、33 项测试、lint、签名、版本号和 ZIP 对齐检查通过；已从 GitHub 公开地址重新下载 APK 并核对完整字节和 SHA-256。Windows 的 180 项测试、程序 / 插件 worker 验证及安装器安装、启动和卸载验证全部通过，产物已提交。Windows 分片已重新合并并验证完整 SHA-256 和 PE 头；记录见 `target/package-download-verification.json`。实际 Windows 显卡 / 任务栏以及手机 / 蓝牙 / 头显体验仍需硬件验收。
