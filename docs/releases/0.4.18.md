# Lumen 0.4.18 Preview 2

Windows 10/11 x64 与 Android 8.0+ 测试预发布，标签 `v0.4.18-preview.2`。Android 版本为 `0.4.18`，versionCode 为 `35`。请同时更新电脑端与 Android 端，再检查海报展示。

- 修复首页最近入库、媒体库中电影与 VR 作品的海报选择：电脑端和手机端统一读取真正的作品海报，不再把视频缩略图当作海报。缺少海报或加载失败时保留占位，不改用视频帧填充。
- Android 电影／VR 卡片保持 2:3 图片区域，海报居中裁切铺满；缺图、加载中和失败时尺寸稳定。其他分类维持原有展示规则。
- 继续观看仍读取当前续播视频文件的指定缩略图，完整等比显示；不回退到作品海报。海报修复不会改变续播图片的用途。
- 纳入已确认的第一阶段 UI 基础组件：官方 Compose Material 3 深浅主题、统一语义颜色与字体、紧凑操作按钮、Chip、海报卡片、搜索、导航及底部抽屉。普通操作按钮视觉最小高度为 32dp，触控区域至少 48dp，普通按钮圆角 8dp，同排操作间距 12dp；大字体允许按钮自然增高。
- 基础组件通过独立预览展示，尚未把其他现有页面整体迁移到这套组件。本版不宣称全部页面已完成美化。

原服务端的封面字段存在海报与缩略图混用，因此电脑与手机原本处于同一版本时也可能出现问题。仅更新其中一端不能完整验证这次修复；请两端都更新。

## 验证状态

- Android 本地完整单元／布局测试：183 项，失败、错误、跳过均为 0；lint 为 0 错误、67 条警告；Debug APK 构建成功。
- 海报回归通过真实 HTTP 图片加载和原生布局验证首页最近入库、电影／VR 媒体库、缺图／失败占位，以及续播只请求视频缩略图。UI 基础层覆盖深浅主题、32dp 视觉与 48dp 边缘触控、禁用操作及窄屏大字等情况。
- 电脑端海报、NFO／刮削图片、异步发现卡片、LAN 封面、续播缩略图等 135 项相关回归通过；完整 Python 收集 839 项。
- Windows 全量测试、构建、安装／卸载，以及 Android 全量测试、lint、持久签名和版本校验均由标签发布门禁执行，全部成功后才公开附件；实际结果随 Release 的验收与签名记录提供。
- 小米 15 上 HEVC 4K 持续播放与拖动后的卡顿尚未确认解决，本版不以 UI 或自动测试结果宣称实机播放问题已修复。

截图及实现范围见 [Android UI 与海报修复说明](../android-ui-0.4.18.md)。截图使用虚构作品和绘制图片，不含用户媒体图片。


Preview 1 的 Windows 门禁发现两处既有 UI 测试同步问题：后台任务以固定 100ms 判断启动，且失败未清理；全屏鼠标移动以单次事件循环判断。补齐有界条件等待、事件送达验证和失败清理，保留取消／落库、鼠标唤回、轮询兜底与自动隐藏断言。使用新标签 `v0.4.18-preview.2`、Android versionCode 35 完整重建，保留 Preview 1 标签；没有因此更改生产导入或播放器行为。

Preview 2 修正后，本地导入／播放器两个完整测试文件 28 项通过；额外慢启动验证通过。Android code35 的 183 项测试、lint 与 APK 打包再次通过。
