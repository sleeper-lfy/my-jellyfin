# Lumen 0.4.11 · 透明字幕、在线发现与 Fans 视频

## 字幕

PC 外挂字幕取消黑色矩形背景，使用透明白字与小范围暗色阴影。mpv 内嵌文字和 ASS 使用透明背景、白字细描边，恢复字号、延时和位置设置不会重新添加黑底。

Android 普通播放和 VR 共用透明文字字幕配置。当前 LibVLC 无法覆盖 ASS 文件自身的黑框样式，位图或烧录字幕的背景属于图像内容，不能通过文字样式消除。

## 发现搜索

- PC、Android 发现页直接显示名称、标签、来源、排序与升降序控件。
- 支持筛选已发现资料，也支持通过插件在线搜索。完整结果先过滤、排序，再分页，不受原推荐前几十条限制。
- 可按首次发现、网站收录时间、名称、年份和来源评分排序，缺少数据的条目排在后面。
- 在线结果保留本次命中范围；切换排序不重新搜索，网站模糊命中不会被本地关键词误删。名称及标签筛选、详情返回、失败重试和后台完成提示同步修复。
- 搜索不会自动下载，也不覆盖已经入库影片的资料。只加载可见封面，并限制后台并发，切页后不使用过期回调更新新列表。
- TVmaze 支持名称搜索；Internet Archive 支持名称与 subject 标签。PC 可在“安装 / 更新站点来源…”更新随软件提供的来源并保留原配置。第三方来源不会自动升级。

真实站点覆盖和可访问性受来源与网络影响；开发环境使用官方响应结构及真实本地 HTTP / JS 链路验证，未将协议测试冒充在线连通验收。

## Fans 作者视频

新增 Fans 视频分类。导入总目录后，每个第一层作者文件夹归为一个条目，子目录视频仍属于该作者，无需季集编号或影视 NFO，不参与影视刮削和推荐。

同一作者分散在多个文件夹时，可在作者详情“更多操作 → 合并同作者文件夹…”勾选其他条目并填写统一作者名。只合并媒体库记录，不移动原目录；保留文件 ID、观看进度、书签、观看记录、收藏和队列。原“其他视频”的相同路径可直接转入；电影、剧集、VR 的相同路径会提示核对，不自动改类。同内容在不同作者目录下仍各自保留，重扫保持目录绑定。

两端上一／下一、蓝牙和自动播放优先切同作者视频，组末再按队列切作者；自动下一开关和整个作者循环继续生效。Fans 使用普通播放，不自动启用 VR。
