# Lumen 0.4.17 Preview 1

Windows 10/11 x64 与 Android 8.0+ 测试预发布。Android versionCode 33，沿用既有签名，可覆盖安装。请同时更新两端以使用缩略图选择修正。

- Android 发现页迁移到官方 Compose Material 3，补齐青蓝色的深浅主题、语义颜色／字体／形状、48dp 触控、edge-to-edge 和资源化中文。其他页面保留现有框架。
- 单一标题和搜索栏、片名／标签分组建议、横向已选 Chip、数量与排序入口，筛选按需打开官方模态抽屉；保留全部既有筛选、在线来源、任务进度、片单及队列功能。
- 两列 2:3 海报、统一收藏按钮、骨架／失败占位、底部安全区与四种页面状态；使用官方下拉刷新和惰性分页，顶栏／搜索随滚动收起和出现。
- 修复发现页年份、评分、多标签参数被置空，以及收藏过滤／在途分页与详情往返中的状态竞争。
- 最近入库恢复原有统一竖向裁切展示；继续观看仍独立使用缩略图。修复 PC 有明确缩略图时手机未采用、合法 NFO 缩略图被误判海报的问题。
- 视频转发增加仅当前会话使用的 16MiB 有界内存读缓存，减少重叠 Range 重复访问电脑；保留鉴权、响应字节和旧拖动取消。诊断新增电脑请求、缓存命中与累计缓存供给。

真实小米 15 HEVC 4K 卡顿尚未确认解决。受控重放验证了重复区间传输的改善，不能替代手机实测；未把 JNI 切换或预取阈值作为未经验证的解决方案。测试预发布需手动安装。
