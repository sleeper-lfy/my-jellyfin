# Lumen 0.4.7 · 基础媒体库功能补全

## 媒体库与观看管理

- PC 和 Android 支持按入库时间、名称、年份、个人评分、时长排序及升降序，保存默认排序。完整结果排序后再分页，缺失评分 / 年份置后。
- 筛选区分未开始、观看中、已完成；手动标记已看 / 未看、重置进度、从头播放。手动标记不会伪造真实观影时长或清除已有统计。
- 两端电视剧详情增加季选择；Android 单集长按可修改观看状态。
- PC 多选后可批量收藏、取消收藏、想看、标记观看、追加标签。
- PC 可仅移出媒体库（确认后清除该条目及其记录，保留原视频 / NFO；再次扫描可能重新入库）。仍在播放的作品须先停止会话。
- PC 支持原目录 → 新目录重定位，后台完整指纹校验后一次提交，保留文件 ID、观看进度、书签及资料。缺失 / 不匹配 / 冲突时不提交；离线且未完成指纹的快速导入文件不能跳过校验。

## 播放、队列与剧照

- PC / Android 新增 0.5–2 倍速和自动下一集开关，保留选择。
- PC 队列支持追加、移除、拖动排序、播放指定项以及停止 / 列表循环 / 单部循环；保留全局范围选择与重新洗牌。
- Android 队列支持追加、移除、上移 / 下移、播放指定项和循环模式；队列保存在手机，PC 队列保存在服务端。
- PC 剧照可全屏查看，左右切换、滚轮 / 按钮缩放、拖动平移；Android 作品 / 单集剧照统一全屏查看，双指缩放、放大后平移、缩小时左右滑动切换。
- Android 新增共享智能片单保存 / 加载；从详情返回复用原媒体库页面，保留已加载分页和滚动位置。
- PC / Android 封面右上角的个人操作只显示图标，取消圆形底色，保留状态颜色和触控区域。

## 验证范围

新增自动化覆盖排序与分页、手动状态与真实统计隔离、批量操作、队列编辑、完整校验后重定位、移除保留原文件、按季浏览、剧照切换、倍速及 Android 返回位置恢复。本地完整 Python 回归 217 项通过、2 项平台检查跳过；Android 55 项测试、lint、构建与同证书签名 / zipalign / 版本校验通过。Windows CI 安装 / 启动 / 卸载验证与最终产物校验在发布前完成。

PC 截图来自实际 Qt 程序的隔离示例资料库；Android 截图来自原生 Activity 渲染测试。没有把云环境验证替代不同 Windows DPI 或 Android 真机的解码、HDR、VR、长时间播放验收。Android APK 沿用原测试签名，可覆盖安装同签名旧版。
