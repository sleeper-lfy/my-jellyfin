# Lumen 0.4.25 Preview 1

Windows 10/11 x64 与 Android 8.0+ 测试预发布。Android versionCode 44，沿用原签名及 ARM32＋ARM64 通用包。

## 自带分类与自定义媒体库

- PC 和 Android 的电影、电视剧、VR、Fans 和其他自带分类只显示未归入自定义库的文件。进入自定义库时只显示该库的文件。
- 同一作品有多个库的文件时，详情、续播、选集、书签、观看状态和当前列表随机按当前库取文件。从自带分类移出本库文件记录时，其他库中的文件记录仍保留。
- 「全部媒体库」和全局随机仍覆盖全部本地媒体。已有文件归属和个人数据直接沿用，建议 PC 与 Android 同时升级。

## PC 内置 TMDB 刮削

- 在「设置 → 影视刮削」粘贴自己的 TMDB API 读取访问令牌，启用后可按中文、原文片名搜索，或粘贴 TMDB 详情链接。支持普通电影、电视剧、动画电影和连载动漫。
- 优先获取简体中文资料，保留来源评分、海报及横图。可用于单片刮削、资料修复及自定义库自动入库，来源优先级由各库设置。
- TMDB 认证、匹配和解析使用模拟响应验证。真实联网取决于可用的读取令牌及 PC 网络。

[媒体库说明](https://github.com/sleeper-lfy/my-jellyfin/blob/main/docs/media-libraries.md) · [获取 TMDB 读取令牌](https://www.themoviedb.org/settings/api)
