# Lumen 0.4.12

## PC 与 Android 实时美颜

- 播放设置增加美颜开关、磨皮强度和肤色提亮，默认关闭，按视频保存并同步。
- 使用共享的肤色估计与保边双边平滑着色器，在本地 GPU 处理，不修改或上传原视频；本版不包含人脸形变和人脸识别。
- PC 支持与 GPU 画质增强独立开关，Qt 兼容内核禁用美颜。
- Android 支持普通视频及 VR 投影；普通视频首次切换渲染通道保留位置/暂停，VR 两眼限制取样范围。

## 本轮累计更新

- 支持手动选择海报/缩略图、横图裁切位置和图片显示大小；剧照单击弹窗，左右切换，再次点击或 Esc 关闭。
- 自动缩略图优先第一张可用剧照；刮削海报比例不合适时从剧照选择或裁切副本。
- 支持演员头像插件批量获取，以及拖本地图片到演员卡片替换头像。
- 修复 VR 电影刮削与同文件夹归集，合并支持搜索、预览和撤销。
- 增加数据库版本迁移保护、脱敏诊断包、一键 EXE 打包文档及可执行发布验收。

## 验证范围

发布附件只来自当前源码构建并附 SHA-256。具体测试结果记录在本次发布说明和构建报告中。

Android APK 为开发测试签名。本次改用持久签名，和 0.4.11 签名不同，不能直接覆盖安装；需要卸载旧手机客户端后安装并重新连接电脑，电脑媒体库保留。没有连接的 Android 真机；手机实际解码、声音、HDR、4K/8K 长时播放和 VR 观感未验证。Windows 的实际扬声器输出、100%/150% DPI、旧版升级和真实插件站点也须按验收矩阵检查。

Windows 完整回归 438 项通过；实际 GPU 美颜输出、与锐化独立切换、暂停位置保持已验证，安装、内置运行库、插件 worker 和卸载通过。Android 编译、lint、73 项单元测试及 APK 构建通过。Windows 原生显示另用桌面抓屏复核画面、窗口/全屏往返、跳转与重开；原维护脚本的窗口抓屏不包含 GPU 子窗口，且边界取样不适合本机显示比例，未将其原始失败冒充成功。

Windows 云端源码验证首次遇到 Chocolatey 504、FFmpeg 缺失，没有形成有效测试证据；重试仍在队列中，取消接口返回 409。本次 EXE 以本机完整回归及安装报告为证据。预发布标签还触发了一项重复稳定版流水线，已请求强制取消；附件没有由该工作流重建或替换。未将排队和取消请求记为测试通过。

按用户要求将本次已上传安装包发布为自动更新可检测的 0.4.12 正式版本；人工验收矩阵仍未完成，状态保留为未验证，不视为人工验收通过。请参考 [美颜说明](../video-beauty.md) 和 [发布验收](../release-acceptance.md)。

- 右键"删除本地文件"：清单确认后删除视频及同名字幕/NFO/图片并移出媒体库，离线或播放中中止。
- 播放控制栏新增"增强 / 美颜"一级开关（PC），Android 播放栏新增"美颜"按钮；安卓密集按钮行与"我的媒体"磁贴布局修复。

验证范围：Windows 回归 462 项通过，安装包经打包后 UI、插件 worker、安装与卸载自动验收；Android 77 项测试通过。真机音频、DPI、旧版升级和真实插件站点仍未验证。versionCode 16，与 preview.1 同签名可覆盖安装。
