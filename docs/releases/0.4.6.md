# Lumen 0.4.6 · Windows + Android

按后续明确要求发布统一 Release，复用已完成 Windows 安装验证及 Android 校验的原始安装包。构建源码为 `37dbbbb7c980baa87e285e5823592770ee28920b`，文件大小和 SHA-256 与 target 已交付版本一致。

## Windows 更新

- 电视剧按文件夹归集，无 S01E01 编号也能导入；优先读取 NFO，兼容 OVA / 第1巻 等文件名，缺号按自然排序补充。保留季目录、重复导入、失败项重试及旧文件的进度 / 书签。
- 任务与诊断改为后台分页读取，每页 100 条；大结果按需预览或导出完整 JSON，避免主线程处理大报告及反复计算列宽。
- 新增 PC GitHub 更新检测、后台下载 / 取消、完整性校验和可选的空闲自动安装。入口：右上工具菜单 → 检查软件更新，或设置 → 软件更新。自动安装前备份资料库，等待导入、任务及 PC / 手机播放结束，保留当前安装与数据位置。
- 剧照在详情页内保持固定预览区域，新图解码完成前保留旧图，重复点击不清空图片或滚动；减少海报、背景与缩略图的重复重绘。

入口、实际 Qt 截图和验证范围见 [本轮 PC 修复](../pc-maintenance.md)。

## Android

版本更新为 0.4.6 / versionCode 9，保留 0.4.5 的 VR 四元数转向、上一 / 下个视频按钮、VR / 蓝牙切换和手机遥控 Windows 关机。Android 8.0+，签名与上一版一致，可覆盖安装。
