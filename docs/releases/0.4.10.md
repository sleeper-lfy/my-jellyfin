# Lumen 0.4.10 · 页面返回、封面放大与响应性修复

PC 和 Android 的标签、演员筛选现在支持逐层返回实际来源页面，恢复搜索、筛选及滚动位置。“为我推荐”“影片发现”与首页同为一级入口；推荐页应用筛选或搜索时保留当前页面，发现资料的筛选包含尚未下载的影片。修复手机快速返回详情、列表后一直停在加载中的情况。

## 封面和演员头像

- 详情封面可点击放大，保持原比例。PC 支持滚轮缩放、拖动及适应窗口；Android 支持双指缩放和拖动。
- PC 女演员墙、演员卡片右键菜单、影片详情的“更多操作”提供“刮削演员头像…”入口。选择来源并搜索，点击正确的头像或姓名后直接保存。
- 头像默认只补充缺失数据，可勾选覆盖已有头像；锁定的演员资料保留。PC 演员墙与 Android 详情显示缓存头像，覆盖后手机不会继续使用旧图缓存。
- TVmaze 更新至 1.2.0 并支持演员搜索，新增 Wikimedia 人物照片来源。在头像窗口选择“安装 / 更新内置头像来源…”可安装、更新并启用，保留原代理等配置。第三方插件可接入独立 `actors` 协议。

头像站点不保证覆盖所有演员。本轮云环境无法连通这些站点，已验证官方响应结构和本地完整流程；真实站点访问仍需在使用环境确认，缺图或访问失败会提示原因。

## 界面响应和播放记录

媒体库、推荐、筛选选项及大图解码在后台执行。筛选窗口立即打开，读取下拉选项时可以直接输入，迟到结果不覆盖正在输入的内容。快速切图只保留正在读取的图片和最新请求。

Windows 原生验证还发现并修复了筛选后台任务已释放后关闭窗口的生命周期问题，避免接受筛选时抛出异常而没有应用条件；回归测试会明确释放任务对象后再接受筛选。

数据库重开不再重复执行建表和全库写入。播放时长、进度和片尾完成状态交给后台合并保存，减少导入占用数据库时的界面等待；重试不会重复累计观看时间，旧记录不会覆盖较新进度或手工重置。退出持续争锁时保存本地恢复快照，下次播放自动重试；如果数据库与恢复文件都无法写入，会明确提示保存失败。

复测中另捕获 Qt 兼容播放器的原生音频对象与 Python 运行锁互锁，现改用 Qt 原生音频实例，避免该路径在后台断开连接时回调 Python。使用真实 AAC 视频完成 80 次快速切源，同时反复创建书签和输入框的回归。修复覆盖已经定位的阻塞源，设备驱动、网络磁盘等其他等待仍需结合实际日志排查。

## 日志位置

Windows 按 **Win+R**，输入 `%LOCALAPPDATA%\Lumen`。也可在“任务与诊断”顶部点击“打开日志目录”或“复制日志路径”。自定义数据目录使用其实际位置。

- `diagnostics.log`：启动、任务异常、数据库保存重试等。
- `ui-hangs.log`：界面超过 3 秒无心跳时记录的线程堆栈。
- `ui-native-hangs.log`：约 5 秒后的 C 级备用记录，可覆盖原生调用持有 Python 运行锁的情况。
- `playback-pending.json`：仅在退出争锁时可能产生的待恢复播放记录，请保留。

仍然卡顿时，可以在窗口未恢复时直接复制日志，并记录发生时间与当时的操作；不需要发送媒体库数据库或视频。
