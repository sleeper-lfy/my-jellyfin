# Lumen 0.4.8 · 播放时直接评分与收藏

PC 和 Android（含全屏、横竖屏与 VR）播放控制栏新增独立的个人操作行，无需退出视频寻找详情页：

- **评分**：直接选择 1–10 分，也可清除个人评分；与来源评分分开保存。
- **收藏**：一键收藏 / 取消收藏，原有收藏记录保留。
- **喜欢 / 不喜欢**：独立于收藏，互斥选择，重复点击可取消为中立；偏好参与推荐，随机播放仍保持等概率。

保存不停止或重新加载视频，也不改变当前集、播放位置或播放会话。切换下一集 / 下一部后，按钮显示当前作品的状态；电视剧评分与偏好保存到整部剧。

Android 在后台保存，等待期间禁用当前作品的重复提交，失败提示并允许重试。保存过程中切换视频仍写入原作品，不会误改新作品。PC 详情及媒体库、手机返回后的详情读取已保存状态。评分面板打开时暂停控制栏自动隐藏。

资料库新增独立喜欢标记，旧收藏 / 评分 / 不感兴趣记录保留；旧资料库及旧版备份在副本上迁移，不改原备份。Android 的独立喜欢操作需要连接同版 PC 服务端。
