# Lumen 0.4.24 Preview 1

Windows 10/11 x64 与 Android 8.0+ 测试预发布，标签 `v0.4.24-preview.1`。Android versionCode 43，沿用 ARM32＋ARM64 通用包和原签名，可覆盖安装。

- 修复 Android 播放器选集时未释放旧解码器与视频连接的问题，切换后真正播放所选文件。进度和单文件设置仍先保存到原文件。
- 选集列表标明当前文件和季集编号，重复选择当前集保留播放进度；自动连播、切到后台时关闭旧选集窗口，取消过期的文件读取。
- 电视剧详情改用现有 Material 下拉组件选择季，保留本次浏览期间的选季，特别篇、不同剧集及不同媒体库互不串用；点击单集绑定实际展示的作品与文件。
- 全局随机和当前列表随机显示“正在准备随机播放”，支持取消。页面刷新不会丢弃明确发起的随机操作，失败可重试，空结果会提示；取消、失败和空结果保留原队列。
- 随机请求使用独立执行通道，避免排队等待浏览请求；PC 的全局随机接口只读取必要文件信息，减少大媒体库生成队列的额外开销。

全局随机仍覆盖全部本地可播放作品，每部电视剧算一个随机对象；当前列表随机沿用现有筛选、媒体库范围和完整分页结果，不改变 PC 队列。缺失文件与越出允许目录的文件仍被排除。无需迁移数据库，schema 3 不变。

建议 PC 和手机同时升级以获得队列生成优化。[选集与随机播放说明](https://github.com/sleeper-lfy/my-jellyfin/blob/main/docs/android-playback-selection-0.4.24.md)。此版修复切换和请求反馈，不代表小米 15 的 HEVC 4K 播放卡顿已通过实机验证。

两端完整测试、Windows 安装／卸载及 APK 原签名校验通过后才公开附件；手机实机播放与局域网交互仍需设备确认，沿用测试预发布。
