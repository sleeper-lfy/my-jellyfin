# Lumen 0.4.19 Preview 1

版本 `0.4.19`，Android versionCode `36`，标签 `v0.4.19-preview.1`。适用 Windows 10/11 x64 与 Android 8.0+。测试与安装验收记录随 Release 附件提供。

## Android 界面重排

按确认的 Bilibili 风格预览重排实际页面：更紧凑的信息层级、轻量操作、分组列表和统一间距。沿用现有 Java View、Compose 与 Lumen 主题，原生操作接入官方 Material 3 组件。

- 首页改为单一搜索、推荐／最近标签、紧凑横向续播卡和两列海报。续播按实际文件读取横向视频缩略图，保留文件身份、已看时间与剩余时间；电影和 VR 列表使用作品海报。
- 媒体库保留全部、电影、剧集、VR、Fans、其他、女演员七类，分类横向滚动；筛选按需打开，观看状态与偏好可换行，底部操作和内容留出间距。
- 发现页统一搜索、来源标签、已选条件、数量和排序，筛选使用底部抽屉。标签先展示一组并支持展开全部，演员、年份、排除标签、评分等现有条件仍可用。海报收藏统一为 48dp 触区内的紧凑圆底。
- “我的”展示实际媒体数量、收藏与想看数量、四项快捷入口和分组设置行。演员墙、演员作品、智能片单、观影统计与连接管理改为独立内容页；数量和统计均来自现有接口。
- 手机队列支持拖动右侧把手排序，保留上移／下移／移除和循环模式。编辑时按作品身份维护播放位置；队列被随机播放替换后，旧编辑器不能覆盖新队列。
- 竖屏播放器使用独立 16:9 视频窗口、右侧轻操作栏、片名、进度和四项快捷入口；横屏与 VR 使用贴边控制。单击显隐、长按临时倍速、字幕、评价、选集、诊断、VR 等功能保留。播放选项改为三个标签与分组列表，自动下一集可直接切换。
- 电脑遥控改为当前媒体卡、三项播放控制、音量和轻操作；电脑任务改为分类与只读状态卡；更新页根据检查、下载、安装、取消状态展示相应操作，保留签名和摘要校验。
- 普通按钮默认色面高 32dp、触区至少 48dp、圆角 8dp；卡片圆角 12dp，动作间距 12dp。底部导航使用官方 Material 组件与紧凑选中指示器，布局正确预留导航与窗口安全区。

## 全局随机播放

首页和“我的”均保留固定的全局随机入口，可独立选择全部本地、电影、剧集、VR、Fans 或其他视频，不继承当前搜索或筛选。当前列表随机仍在列表操作中，按完整列表范围生成队列。两者使用手机独立队列；请求失败、空结果或旧版电脑不支持时保留原队列。
