# Lumen 0.4.23 Preview 1

Windows 10/11 x64 与 Android 8.0+ 测试预发布，标签 `v0.4.23-preview.1`。Android versionCode 42，保留 ARM32＋ARM64 通用包与原签名。

- 修复 Windows 托盘右键取消菜单时可能误判 Win32 残留错误，导致图标消失和后台退出。
- 菜单在窗口回调外执行，合并打开期间重复的右键通知；临时菜单错误保留托盘与后台，允许再次打开。
- 设置第一栏新增「启动与后台」，集中展示开机自启动、静默启动、关闭窗口及真正退出的行为。
- 新增独立的「静默启动（仅显示托盘，不打开主窗口）」开关，默认关闭；下次首次启动生效，保留已启用的局域网服务与目录监听。
- 双击托盘、选择“打开 Lumen”或再次运行快捷方式可恢复主窗口；取消菜单继续保留图标，真正退出沿用安全保存流程。

[设置面板与使用说明](https://github.com/sleeper-lfy/my-jellyfin/blob/main/docs/windows-tray-startup-0.4.23.md)。Android 同步版本，功能沿用 0.4.22；自定义媒体库、独立刮削整理规则与原有个人记录保留。数据库仍为 schema 3。

两端完整测试、Windows 安装／卸载验证及 APK 原签名检查通过后才公开附件。真实隐藏图标栏的鼠标操作、Windows 登录与手机设备检查保持人工待确认，因此沿用测试预发布。
