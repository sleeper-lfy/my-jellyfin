# Lumen 0.4.5 · VR 转向、视频切换与手机关机

## Android 播放

- 修复大幅抬头接近或越过 90° 时，VR 视角突然左右旋转、俯仰折返的问题。使用相对四元数姿态，保留灵敏度、平滑、上下反转和回正设置。
- 普通和 VR 播放页底部直接显示上一 / 下个视频按钮，与蓝牙下一首 / 上一首及自定义映射共用逻辑。
- 当前作品有多个文件时先切换相邻文件；电视剧在本剧内切集，首末集不循环；VR / 电影等单文件作品可切换当前分类、搜索、标签、演员、年份及收藏范围中的相邻作品。随机队列支持双向切换且不循环。列表查找在后台分页执行，失败可重试。

## 手机控制 Windows 关机

两端均升级后，在 PC **设置 → 局域网 / Android** 中开启服务、手机遥控和 **允许手机请求电脑关机**。手机使用相同服务地址及密钥连接，在 **电脑遥控 → 关闭电脑** 确认。

电脑显示 15 秒倒计时，手机和电脑均可取消；禁用遥控权限或退出 PC 程序也会取消尚未执行的倒计时。到时后台请求 Windows 正常关机，不使用强制关闭程序选项；如其他程序有未保存文件，Windows 可能要求在电脑上处理。非 Windows 系统不支持远程关机。旧 PC 端不支持此功能，需要同时更新 EXE。
