# Lumen 0.4.15 Preview 2

Windows 10/11 x64 与 Android 8.0+ 测试预发布。Android versionCode 30，保持既有签名，支持覆盖安装。真实设备和 HEVC 4K 持续播放验收仍需完成。

- Android 全应用统一深色青色样式、圆角输入框、图标与弹层；首页、媒体库、详情、发现、我的、连接、更新、电脑遥控和电脑任务沿用同一视觉规范。
- 媒体库底部固定首页、媒体库、发现、我的四项横向导航；分类、排序与列表操作保持横排。海报按实际窗口宽度重新测量，保持 2∶3 比例，适配分屏和旋转。
- 继续观看独立显示作品标题、续播文件／集数、已看与总时长、剩余时间和进度。长身份信息可展开；时长未知时明确显示未知，不伪造剩余时间。
- 筛选改为观看状态、个人偏好、标签／演员和年份分组，高级条件折叠；支持包含全部、包含任一及排除标签。排除类型不要求先逐部标记“不喜欢”。草稿重置不直接应用；条件随页面恢复并用于同范围播放队列与智能片单。新标签组合需同时更新电脑端。
- 播放器竖屏采用视频为主体、右侧轻量操作、底部影片信息与细进度的布局；横屏采用影院式控制。字幕、音轨、倍速、选集、书签、我的评价及队列保留，设置分为常用、画面、高级。
- Android 播放中的视频空白区按住约 400ms，临时请求 2×，松手恢复原先实际速度，例如 1.5×。移动、第二指、取消、失焦、暂停／切片源及退出会清理临时速度；按钮与进度条不触发，不写入固定倍速偏好。VR 保留转向／缩放交互，不复用普通视频长按。
- 修复 Android 暂停时，心跳将手动隐藏的控件重新唤回的问题；播放状态刷新保留用户的控制层可见性。
- PC 与 Android 均可单击视频空白区域显示／隐藏播放控制。Android 单击优先执行控制层切换，播放／暂停通过播放按钮完成；PC 手动隐藏后，普通鼠标移动不会立即将控制层唤回。
- PC 首页“我的媒体”移动到最上方，卡片宽度与继续观看一致，按可用空间自动换行。
- PC 作品、首页媒体行和集数右键菜单新增“在系统文件夹中显示”。单文件直接定位，多文件先选择；Windows 选中文件，macOS 定位文件，Linux 打开所在目录。离线文件提示错误，不打开其他目录。
- 保留 Preview 11 的旧视频 HTTP 请求取消修复，避免拖动后旧读取占满转发线程。

长按倍速改变的是播放速率，不提供服务端转码，不保证所有 4K 片源都可流畅 2× 播放。测试预发布通过发布页手动安装，不替换稳定最新版。
