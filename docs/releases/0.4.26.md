# Lumen 0.4.26 Preview 1

适用于 Windows 10/11 x64 和 Android 8.0 及以上。Android 安装包沿用原签名，versionCode 为 45。

- Windows 和 Android 的「影片发现」新增下载分类选择。可以归入自带分类，或选择支持该影片类型的自定义媒体库。
- Windows 第三方刮削兼容已有本地媒体的分类，避免候选资料只提供通用类型时误报「候选媒体类型不匹配」。
- 同时使用手机和电脑时，建议两端一起升级，以使用下载分类的新选项。

本预览版沿用已通过自动验证的原始安装包。[原始构建](https://github.com/sleeper-lfy/my-jellyfin/actions/runs/46114710729)
