# Lumen 0.4.2

Windows 与 Android 同版更新，不包含 2D 视频的 VR 观看功能。

- 重做深色媒体库、筛选面板、海报卡片和详情布局，统一收藏、想看及评分操作，操作后保留滚动位置。
- PC 改为覆盖完整显示器的无边框全屏，并通知 Windows 将任务栏置于全屏窗口后方；退出恢复窗口。
- 支持电影、电视剧和 VR 的默认下载目录；HTTP 视频下载后关联影片资料、NFO 与图片，磁力交给外部工具。
- 详情刮削使用封面和标题候选，一次选择更新当前页面；支持标签、演员和年份输入筛选。
- 安卓可发现局域网服务端；保留 LibVLC 播放、视频比例适配、VR180 回正和缩放、蓝牙自定义控制。
- 仓库首页加入 PC 运行截图与明确标注的 Android 测试预览。

## 下载与安装

- **Windows 10/11 x64**：下载 `Lumen-Setup-x64.exe`，运行安装向导。安装器尚无商业代码签名。
- **Android 8.0+**：下载 `Lumen-android-debug.apk`。这是沿用现有本地测试密钥的开发签名包；若旧包签名不同，需卸载旧版后安装并重新填写连接信息。
- 两个文件均附带 `.sha256` 校验文件。EXE 是完整安装器，无需手动拼接分片。

构建会先运行 Windows 测试、打包与静默安装 / 启动 / 卸载验证，并检查 Android APK 的源码匹配、哈希与签名，随后统一发布。自动化检查不代替 Windows 真机任务栏 / 显卡和安卓手机 / 头显验收。
