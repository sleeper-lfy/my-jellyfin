# 整理命名模板与执行预览

在影片详情的“更多操作 → 文件与版本 → 整理文件”打开命名与整理窗口。先选择目标根目录，填写目录模板和文件名模板，再点击“生成预览”。预览显示原路径和目标路径，每页 100 个文件；修改目标或模板会使旧预览失效。核对后点击“确认并执行”。生成预览只读取文件与校验，不改名、不移动视频。

分类默认模板统一在“媒体管理 → 分类规则与来源”编辑。监听目录的详情可设置整理目标专用模板，并显示实际继承结果；使用同一整理目标的目录共用这份模板。目录草稿与目标模板一起通过“保存目录设置”写入。

## 模板

- `{code}`：可唯一识别的影片编号。
- `{title}`、`{year}`、`{year_suffix}`：片名、年份、带括号的年份。
- `{stem}`：原文件名（不包含扩展名）。
- `{part}`：从 CD / DISC / PART 后缀识别的分段标记。
- `{season}`、`{episode}`：两位季号和集号。
- `{version}`：本次整理计划按文件 ID 排序的版本序号，如 V01。

例如目录 `{code} - {title}{year_suffix}`，文件名 `{code}`。目录模板可使用 `/` 分层，文件名模板不含扩展名。留空沿用旧行为：按标题（年份）归档并保留原文件名；电视剧增加季目录，其他视频保留原目录结构。

编号、年份或季集字段缺失时，引用这些字段的模板会提示补齐资料，不会生成猜测值。非法字段、格式化表达式、绝对路径、`..`、符号链接越界及已存在的不同内容目标均被拒绝。模板产生同名的分段会保留 CD 编号，电视剧保留季集编号；同一目标下多个版本补 V 序号，并再次检查所有目标冲突。

## 默认规则

“媒体目录 → 命名规则”可配置分类默认规则或目标目录规则。目标目录规则优先于分类默认，设置为两个空模板可为该目标恢复旧命名方式。保存规则不会立即处理已有文件；后续手动整理及自动入库会共用这些规则。

整理窗口也可勾选“执行时将本次模板保存为该目标目录的默认规则”。没有勾选时，只影响这次整理。

## 字幕、NFO 和图片

同名字幕、语言 / forced 字幕、同名 NFO 及图片随视频模板一起改名。NFO 引用的本地图片另按原相对文件名复制到目标，保留 XML 引用；共享源图保留，避免影响其他影片。电视剧的 `tvshow.nfo` 复制到目标整剧目录。常见 poster/fanart 图片只在该作品拥有源文件夹中所有视频时一起复制。

复制共享图片属于整理日志的一部分，同样进行完整校验和目标无覆盖发布；中断可通过已有文件整理任务恢复。视频仍只在复制并校验成功后删除源文件。无法安全读取或指向目录之外的 NFO 图片引用不会跟随复制，不会进行联网图片下载。

本轮包含生成真实 NFO 后多分段整理、图片引用有效性与共享图片中断恢复测试；尚未在 Windows 真机验证路径和文件占用差异。
