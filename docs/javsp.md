# JavSP 本地辅助刮削

PC 的“影片来源 · 安装与检测”新增“接入 JavSP 本地辅助引擎”。这是固定内置来源 `javsp-local`，用于编号电影与 VR，支持普通编号和 FC2 编号。Android 可使用 PC 同步后的资料，不在手机上运行 Python。

## 准备与配置

1. 按 [JavSP 上游说明](https://github.com/Yuukiy/JavSP)单独安装源码、其要求的 Python 版本和依赖，并配置可用的 `config.yml`。上游具有自己的许可和使用条款，应以其仓库当前说明为准。Lumen 不下载、附带或自动更新 JavSP。
2. 在“接入 JavSP 本地辅助引擎”选择独立环境的 Python，例如 `D:\JavSP\.venv\Scripts\python.exe`；源码目录选择包含 `javsp/config.py`、`javsp/datatype.py` 的项目根目录。不能选择打包后的 `JavSP.exe` 或 `Lumen.exe`。
3. 选择配置文件，留空使用源码目录的 `config.yml`。抓取器按该文件 `crawler.selection.normal` / `fc2` 的顺序运行，每次最多 8 个来源。代理、超时、站点地址等由 JavSP 自身配置管理。
4. 点击“检测环境”。它在独立进程中导入配置和数据类型，不请求影片站点；缺依赖、配置格式不兼容会明确报错。勾选“保存后启用 JavSP 来源”，再点击“检测并保存”。默认不启用。
5. 返回影片来源页面，选 JavSP、输入一个已知编号，点击“检测来源”检查真实搜索和详情。随后到“分类默认规则”，将其配置为电影 / VR 的首选或备用来源。只启用来源不会改变已有的自动入库规则；也可在导入时选择或在详情手动刮削。

## 资料与图片

桥接器只向引擎传编号、引擎根目录和配置路径，不传视频路径，不调用上游主程序的扫描、整理、移动、更新入口。返回标题、简介、演员、导演、标签、日期、评分、封面、剧照和来源页面；不接收磁力、下载链接或预览视频。多个来源只合并编号一致的资料，同一字段使用第一个非空值。普通编号如 `ABC-123`、`abc_123` 统一为 `ABC-123`；`FC2-123456` 与 `FC2-PPV-123456` 统一为后者。

候选通过原有唯一编号检查，再交给原有合并逻辑。VR 类型、手动锁定字段、本地 NFO 和自定义封面的保护规则保持有效；无法匹配时进入现有重试 / 人工确认流程，不会据此移动视频。

JavSP 的站点网络请求使用其自身的配置与权限。Lumen 下载封面、演员图和剧照时仍检查精确域名、HTTP(S)、代理、响应大小和跳转。配置窗口列出默认允许的补图主机；其他主机在“额外补图域名”中填写，以逗号分隔，不含协议、端口、路径或通配符。站点资料成功而图片失败时，先检查图片真实主机和应用代理，不必重新导入视频。

## 任务与兼容边界

每次外部抓取总预算 180 秒，支持现有取消 / 退出机制。搜索候选在本地缓存 10 分钟，详情直接复用同一候选，避免重复请求；修改引擎配置或更换环境后缓存失效。候选过期请重新搜索。

外部 JavSP 是用户安装并信任的 Python 程序，不受普通 JS 插件沙箱约束；Lumen 只提供固定的桥接入口，不允许 JS 插件自行执行命令。上游模块 API 若改变，需要更新桥接器；目前适配 `javsp.config.Cfg`、`javsp.datatype.MovieInfo` 和 `javsp.web.<来源>.parse_data(info)` 接口。不支持独立 EXE、无编号电影或电视剧季集识别，也不执行上游翻译、封面裁切等完整整理流程。

自动验证使用合成的 JavSP API，通过真实子进程测试文件通信、编号、FC2、缓存、取消与权限。未配置用户实际的 JavSP 环境，未据此宣称任何真实站点可用。
