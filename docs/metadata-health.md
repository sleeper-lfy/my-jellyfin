# 资料修复与强制更新

从电脑端“媒体管理 → 资料修复”打开资料补全面板，检查本地电影、电视剧与 VR 影片。可按分类查看，列出缺失简介、标签、演员、海报、待补图片数量，以及受锁定或 NFO 保护的字段和已有来源。操作按钮明确显示处理全部或选中的影片数量。手工选定海报、NFO 海报和已缓存站点海报会保留；FFmpeg 自动截图作为临时缩略图，不会误判为已补齐站点海报。

默认选择“仅补充缺失资料与图片”。需要重做已有展示资料时，切换为“强制覆盖影片资料与图片”；列表会包含当前分类的全部本地影片，包括资料完整的影片。可多选指定影片，未选择时处理表格内全部影片，执行前会显示数量、影片清单及覆盖范围。

强制模式重新获取标题、年份、简介、标签、演员、导演、别名、海报、缩略图和剧照，替换手工选择图片，清除旧 NFO 展示资料、图片保护及资料锁定。来源未提供的展示字段也会清空，不将旧字段混回新资料。刷新所用来源的链接与站点评分；作品 ID、来源身份校验和历史名称索引继续保留。

个人评分、喜欢／收藏、想看和不喜欢状态保留；视频文件、文件归属、播放进度、播放记录、书签与队列不变。不移动或删除视频，也不改写原 NFO / 图片文件。Javinizer-Go 和 JavSP 绕过本地查询缓存，图片重新请求并保存为独立缓存。普通补缺仍遵守原来的锁定与 NFO 保护。

强制更新按唯一候选、来源 ID 和外部编号校验，不会自动合并其他作品。来源匹配失败时保留原资料；资料或自选图片在查询 / 下载期间被其他操作修改时，拒绝本次覆盖并提示重新检查。图片在数据库写事务外准备，成功后一次提交展示资料；停止时不提交当前影片，已完成影片保留。个别图片失败会在报告中列明，仍可保存新资料及其他成功图片，缺失图片可以再次重试。

- **一键补全缺失资料与图片**：未选择行时处理当前分类表格内全部影片；选择多行时只处理选中影片。按已有来源、分类默认来源及备用来源尝试，也可明确指定一个已启用的影片来源。
- **仅重试缺失图片**：只下载已有图片 URL 对应的缺失海报、演员照片和剧照，不重新搜索影片或请求详情。没有图片 URL 的演员照片需要先通过演员头像功能获取来源。
- 已关联影片按来源 ID 获取详情；没有关联时使用当前自动入库的唯一编号 / 标题匹配规则，不采用搜索结果首条。外部编号冲突、来源已关联其他作品、类型不符时拒绝写入。
- 普通补缺只写入仍为空的资料字段；已有内容、个人评分、收藏、标题、年份、文件与观看进度不变。手动锁定字段与本地 NFO 字段保持，包括锁定的空标签 / 演员列表。可手动解除字段锁定，或明确选择强制覆盖模式。
- 图片下载走插件已声明域名和代理规则。下载完成后再次检查锁定、已有图片及演员身份，防止覆盖期间的手工编辑。已成功缓存的图片不重复请求；每张图片的错误独立记入任务记录，再次点击图片重试时只处理仍缺失的图片。
- 暂停 / 停止使用现有后台任务控制；完成的资料和图片保留。取消后可重新检查，修复报告显示每部影片的已补字段、图片数量及未完成原因。

实现不会移动或删除原视频，不写回 NFO，不自动安装或启用来源。来源可用性依赖实际网络及站点，本功能的验证使用本地 HTTP 图片服务和可控插件响应，不代表真实站点验收通过。
