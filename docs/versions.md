# 重复候选与版本对比

电影 / VR 详情 → 更多操作 → 文件与版本 → 版本对比 / 默认播放，或媒体管理 → 整理与版本 → 重复候选与版本对比。

长文件名省略显示并提供完整提示；选中后在表格下方显示完整路径和读取状态。各参数列限制宽度，避免文件名独占整个表格。

后台读取每个视频的真实分辨率、编码、大小、时长、音轨与内嵌/同名外挂字幕。文件路径、大小及修改时间不变时复用结果；损坏/离线文件单独显示原因，不影响其他版本查看。

选择版本可以直接播放、设为默认、恢复自动选择或打开所在目录。默认仅作用于所属电影 / VR，电视剧继续按季集选择；已完成版本不遮挡同作品尚未看完的其他版本。失效路径不会强行作为默认播放目标。

“仅移出选中版本”需要确认，会移除该文件的库内记录及对应播放历史，不删除磁盘视频；监听目录下次扫描可能重新导入。正在播放的文件不能移出。

重复面板按相同影片编号和已有完整指纹提供候选组。相同编号也可能是分段或不同画质，既有指纹也可能因文件被外部修改而过时，因此不自动删除任何候选文件。可打开版本对比和文件目录进一步核对。
