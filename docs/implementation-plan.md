# 分阶段开发与验收

用户要求按阶段推进；工程依次建立了数据/播放 → 插件/安全整理 → 筛选/随机 → 统计 → 演员/推荐 → 发现，并在集成阶段反复回归。

| 阶段 | 实现范围 | 自动化验收 |
|---|---|---|
| 1 桌面媒体库 | Qt 框架、统一深色界面、三类型、扫描引用、缩略图、真实播放、恢复和 SQLite | 生成真实编码视频→扫描→缩略图→解码帧→暂停/跳转→保存位置→重开数据库 |
| 2 刮削与整理 | JS 进程隔离、网络权限、插件管理、代理、分类、来源、锁定、自动匹配、日志、安全移动 | 本地 HTTP→插件→标准元数据→锁定合并；真实视频+字幕移动；冲突/源变更/重试 |
| 3 搜索与随机 | 多标签任一/全部/排除、年份/个人分/观看/收藏/目录、智能片单、完整洗牌、整剧单位 | 125 条筛选跨分页；1 万对象完整候选；无重复与重启恢复；剧集恢复 |
| 4 评分与统计 | 1–10 整数/可空、会话实际秒数、>600 边界、日周月年、偏好、重复观看、年报 | 可控时钟边界、暂停/缓冲/前后跳转/倍速；实际播放集成；跨年实际日期归档 |
| 5 演员与推荐 | 女性显式筛选、别名合并、算术平均、最低已评分数量、排序、详情、可解释推荐 | 9/8/10→9.0；未评分/多版本/未知性别；评分驱动排序和随机独立 |
| 6 发现 | 插件定期刷新、站点/分类筛选、跨站来源去重、本地标识、想看/负反馈、来源跳转 | HTTP 发现去重；发现/本地实体合并；TVmaze 请求链与三种时间语义 |

## 交付质量关卡

1. 源码测试、Qt 页面/对话框实际渲染、真实视频解码、数据库恢复通过。
2. PyInstaller 本机打包并启动、打包后的 JS worker 可用。
3. Windows CI 同样跑测试、打包并验证 exe，再上传 zip；不能用 Linux 包声称 Windows 已验证。
4. TVmaze/图片域名开通后执行 live 验证；不在无网络时宣称真实站点成功。
5. Windows 实机补充音频、中文/长路径、外置磁盘、125%/150%/200% DPI、多字幕格式和主流编码验证。

剩余差距、已执行结果与外部阻碍由 `docs/progress.md` 跟踪，不把计划命令当成执行结果。
