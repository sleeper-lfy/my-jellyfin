# 界面导航与管理入口

本说明对应当前源码。现有安装包需要重新构建后才包含这些调整。

## 电脑端

侧栏默认显示，分为媒体库、我的和管理。媒体库包含电影、电视剧、VR、Fans、其他视频、演员与影片发现；我的提供收藏、想看、智能片单和历史统计。顶部保留搜索、电脑播放队列、任务、管理和设置，队列入口不会直接开始随机播放。

列表常用排序、视图和筛选就地展示，低频显示和维护操作放在列表“更多”。进入多选后显示已选数量与批量操作，NFO 导出只针对所选影片。退出多选后收起操作条，当前影片的导出位于详情菜单，不再从全局工具猜测操作范围。

打开智能片单时同步其排序设置，切换排序保留片单条件。继续观看应用筛选后仍保持续播范围；推荐和续播页的随机播放使用当前列表全部结果，包含尚未显示的后续页。

影片详情保留播放、收藏、想看和个人评分；更多菜单分为播放与观看、资料与图片、文件与版本，移出库和删除磁盘文件单独放在末尾。全局图片显示大小移出影片菜单。主操作允许换行，封面在窄窗口收缩，视频和季集提前显示，长简介与演员列表可展开。

## 媒体管理

同一个管理窗口提供目录与入库、分类规则与来源、资料修复、整理与版本、导入导出五个页面。

- **目录与入库**：直接刷新当前分类或选中目录。目录详情显示监听源目录、首选及备用来源、整理目标、实际命名模板与继承关系。目录修改先应用到草稿，再点击“保存目录设置”生效；未保存时有提示，关闭会确认放弃。
- **分类规则与来源**：统一保存首选来源、备用顺序、整理目标和分类默认命名模板。来源安装与检测使用独立窗口，安装后可重新读取来源配置。
- **资料修复**：文件路径体检只生成报告，资料补全可以写入缺失资料与图片；界面明确区分。
- **整理与版本**：核对重复候选和不同版本，查看目录规则；当前影片的整理预览和默认播放版本仍从详情进入。
- **导入导出**：导入文件夹，或明确选择分类后预览和导出 NFO。

目录覆盖优先于分类默认。目标目录专用命名模板由使用同一整理目标的目录共用，不能把它理解为仅修改当前监听源目录。VR 预设、规则表单等较长内容可滚动，保存和取消保持可达；版本表不会因长文件名把媒体参数挤出整个窗口。

## Android

底部主导航固定为首页、媒体库、发现、我的。媒体分类放在媒体库内；首页显示继续观看和分类快捷入口。我的包含收藏、想看、智能片单、观影统计、手机播放队列、电脑任务及连接设置等入口。

排序与筛选属于当前列表，已选筛选条件随内容滚动。详情的更多菜单只处理当前影片，包括从头播放、在电脑上播放、观看状态、加入手机队列和相关电脑任务；更新与连接设置不出现在影片菜单里。视频和选集提前，续播文件名和剩余时间独立显示，不塞进固定高度的播放按钮。年份使用独立输入行，演员姓名允许随文字增高。

手机队列支持在同一窗口连续调整顺序和移除。手机播放队列与电脑播放队列保持各自原有存储，界面明确名称，不宣称跨端同步。

智能片单内排序、搜索和筛选保留原片单范围。随机播放使用当前列表的全部可播放结果，不受已加载页数限制；手机端需要新版电脑接口，旧版会提示更新并保留现有手机队列，不会改为全库随机。

播放器主栏保留五个图标操作：上个视频、后退、播放 / 暂停、快进、下个视频；全屏在顶栏。播放选项按常用、画面与控制、高级等分组，美颜、VR、方向在画面设置中。按钮有可访问说明，播放和进度操作采用至少 48dp 的触控高度，文字区域可随字号增高。

## 任务中心

两端按全部、进行中、待确认与重试、失败、历史分组。电脑端继续支持确认、重试、停止和完整报告；手机端显示电脑执行的任务、进度与原因，并支持分类、分页、刷新和当前影片范围。手机端目前只读，确认和重试需在电脑任务中心完成。

手机的任务列表需要本轮电脑端接口。旧版电脑端会显示更新提示；网络失败保留原地重试入口。任务接口经过鉴权，只返回白名单状态、进度和原因分类，不传原始报告、文件路径或访问密钥。

Android 的图片下载使用独立的两个工作线程，不占用列表、详情和操作请求的线程。重复图片请求共用下载，可见图片优先；切换页面或应用进入后台时取消旧图片，回来后从内存缓存恢复，缺图重新请求。

后台任务继续遵守设置中的总并发上限，并分别限制磁盘任务、媒体处理和网络来源请求。手动提交的任务优先于等待中的自动任务。电脑播放或手机正在通过电脑播放时，目录监控、自动补充媒体、巡检和定期发现会在安全点让出后台名额，暂停或结束播放后恢复；手动操作仍可执行。正在运行的 FFmpeg 先完成或响应取消，再让出资源，不强行中断文件整理。移动文件前仍建议停止对该文件的播放。
