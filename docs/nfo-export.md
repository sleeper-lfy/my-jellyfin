# 导出当前资料到 NFO 和图片

电脑端影片详情“更多操作 → 资料与图片”导出当前作品；列表多选操作条导出已选作品；“媒体管理 → 导入导出”按明确选择的分类导出。弹窗显示作品数量。适用于有本地文件的电影、电视剧和 VR；不会改动数据库、移动视频或联网下载图片。

- 电影 / VR 使用视频同名 `.nfo`。电视剧使用剧目录的 `tvshow.nfo` 和视频同名的单集 `.nfo`，包含明确的季集编号，特别篇 season 0 保留。
- 导出当前标题、年份、简介、标签、演员姓名 / 角色 / 性别 / 别名、外部编号、个人评分及对应视频的播放位置、完成状态。个人评分写入 `userrating`；来源评分与个人评分分开。不会凭已完成状态编造实际观看次数，只用 `playcount=1/0` 表达完成标记。
- 图片只复制本机已有的有效海报、演员头像、背景和剧照。文件使用 `lumen-角色-内容哈希` 名称，NFO 使用相对路径引用。不存在或损坏的图片报告提示，不联网补图。
- 默认跳过已有文件。勾选“更新已有 NFO / 同名图片”后，先保留原文件的 `.lumen-backup-*` 副本，再通过同目录临时文件原子替换。已有 NFO 的未知字段和注释保留；同名演员节点的未知字段也保留。
- 无法解析、含 DTD / 实体声明、根节点类型不符、符号链接或并发变化的目标不会被覆盖。多个作品争用同一个不兼容的目标时，整个计划停止写入并报告。
- 同一作品的不同文件格式若具有相同文件名，必须共享一份同名 NFO；使用默认版本（未指定时为首个版本）的播放信息，并提示该限制。各视频原文件保持不变。
- “检查导出路径”只生成计划。执行后显示写入 / 跳过 / 备份数量和错误；完整结果保存在任务记录。取消时已完成的文件保留，当前尚未发布的临时文件清理，不留下半份 XML。

此功能输出 Jellyfin / Kodi 常见 NFO 字段，并通过本项目 NFO 读取器进行回读测试；不代表已覆盖 Jellyfin 的全部扩展字段或多用户数据库迁移。演员别名作为 `alias` 扩展节点保留，本项目现有 NFO 读取器尚不读取该扩展。安装包需重新构建后才包含本功能。
