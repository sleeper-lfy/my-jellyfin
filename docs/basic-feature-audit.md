# 基础功能核查（0.4.6）

以下表格保留 0.4.6 的历史核查结论；0.4.7 对应实现见文末。

核查日期：2026-10-24。以原始需求、UI 规范、Android 说明及当前源码为依据；后续用户明确调整优先于初始文档。本次是文档与代码核查，不等同于 Windows / Android 真机验收。

## 文档要求与实现的差距

| 项目 | 设计依据 | 当前实现与差距 |
| --- | --- | --- |
| 电视剧按季浏览 | [需求第三节、第十三节](requirements.md)：电视剧 → 季 → 集，季与集列表 | 季集数据、编号、选集、连续播放已实现；PC `Details` 和 Android `renderDetail` 仍平铺全部集数，没有季选择或按季分组。属于交互不完整。 |
| 观看状态筛选 | [需求第七节](requirements.md)、[UI 筛选规范](ui-design.md) | PC 有已观看 / 未观看，核心将有任意观看时间或进度的作品计为已观看，不能分别筛选未开始、进行中、已完成；Android 筛选没有观看状态入口。原始文档没有细分这三个状态，不能据此称三态均为原始硬性要求。 |
| 智能片单 | [需求第七节](requirements.md)：保存常用筛选条件 | PC 已有保存、加载；Android 没有对应入口。原始需求针对 Windows，Android 属于跨端能力差距，并非未完成原始 PC 要求。 |
| 实机体验验收 | [阶段计划质量关卡](implementation-plan.md)、[Android 解码验证范围](android.md) | 自动化和页面渲染不能替代不同 Windows DPI、系统栏、Android 设备解码 / HDR / 长时间播放验收；相关文档明确保留真机验证项，不能将功能有代码视为全部验收通过。 |

证据：`src/lumen/ui.py` 的 `Details` 文件列表、`FilterDialog`、`save_list` / `load_list`；`src/lumen/core.py` 的 `query`；`android/app/src/main/java/net/lumen/media/MainActivity.java` 的详情文件循环、筛选面板和 `listPath`。

## 原始设计也漏写的基础功能

以下是新增补全建议，不冒充原始文档要求；本次没有实现这些功能。

| 优先级 | 功能 | 当前情况 / 建议补全 |
| --- | --- | --- |
| 高 | 媒体库排序 | 核心查询固定 `added DESC,id DESC`，PC / Android 无排序选择。增加名称、年份、入库时间、评分、时长及升降序，并保存偏好。演员墙已有独立排序，不受此结论影响。 |
| 高 | 手动管理观看状态 | 没有标记已看 / 未看、重置单集进度、从继续观看移除的常规入口。已有自动记录、恢复与连播。手动改状态应与真实观看时长统计分开。 |
| 高 | 批量操作 | PC 海报列表仅单选；缺少多选后收藏、标记观看、编辑标签等操作。已有批量导入、匹配、NFO 补图，不能笼统说没有批处理。 |
| 高 | 移除条目与失效路径修复 | 没有常规“仅移出媒体库”入口；目录迁移后缺少保留原 ID / 进度的路径重定位。已有监控目录管理、健康检查、文件整理和重复作品合并。若增加物理删除，应单独提供受保护的回收站操作。 |
| 中 | 播放倍速 | PC 后端有速率接口，但两端播放器缺少用户入口；后端能力和统计测试覆盖倍速不代表用户能操作。 |
| 中 | 季分组与连播选项 | 除按季浏览外，缺少关闭自动下一集的设置。已有 PC / Android 上一集、下一集，不重复列为缺失。 |
| 中 | 可编辑播放队列 | 已有洗牌、不重复、上一项 / 下一项和恢复；缺少用户指定顺序、追加、移除、拖动排序与循环模式。 |
| 中 | 剧照完整浏览 | 已有剧照展示；缺少统一全屏图集、左右切换和缩放。Android 单集剧照与作品剧照的点击行为尚不一致。 |
| 中 | 返回保留浏览位置 | Android 从详情返回会重建列表并从第一页加载，缺少列表位置恢复；详情内原地修改个人状态已保留滚动。 |

建议先补排序、观看状态和按季浏览，再做批量操作、路径修复与播放器常用设置。Android 离线观看、2D VR 观看和新的 GPU 增强算法不在本轮建议范围内。

## 文档本身需要维护

- 原始需求的“不提供下载”已被用户后续明确要求 HTTP / 磁力下载覆盖，不能按旧句子删除现有下载功能。
- `architecture.md` 仍主要描述 Qt 播放器，当前 Windows 已优先使用 libmpv、Qt 作为兼容回退；文档需要同步。
- `implementation-plan.md` 的自动化验收摘要不能直接用作所有产品交互已完成的证明；后续应按功能分别记录代码、界面入口、验证和交付版本。

## 本次图标调整

按用户追加要求，PC 与 Android 封面右上角的个人操作取消圆形底色，只保留图标与状态色；点击区域保留。UI 规范已同步。本次没有打包或发布 Release。
