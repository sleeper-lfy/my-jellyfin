# 导航、封面与界面响应修复

本页修复已包含在 [0.4.10 Windows + Android Release](https://github.com/sleeper-lfy/my-jellyfin/releases/tag/v0.4.10)，历史 0.4.9 安装包不包含这些修改。

首页、为我推荐、影片发现均为一级导航。详情中的标签、演员可继续筛选，返回逐层回到来源详情及原列表，并恢复筛选与滚动位置，详见 [导航说明](navigation.md)。

PC 和 Android 详情的封面均可点击放大，保持图片比例。PC 支持滚轮缩放、拖动和适应窗口；Android 支持双指缩放与拖动。PC 大图读取、尺寸检查和解码在工作线程进行，快速切图只保留正在读取的一张与最新请求，不排队解码所有途经图片。

女演员墙的“刮削演员头像…”按钮、演员卡片右键菜单，以及影片详情的“更多操作 → 刮削演员头像…”提供独立头像匹配。输入本地演员姓名，选择启用的来源，点击正确候选后直接保存。默认补充缺失头像，可勾选覆盖；锁定的演员字段保留。PC 演员墙和 Android 详情显示已缓存头像。内置 TVmaze 与 Wikimedia 来源的安装、升级和第三方 `actors` 协议见 [插件开发文档](plugin-development.md#独立演员头像)。站点不保证覆盖所有演员，当前云环境无法验证真实站点连通，缺图或访问失败会如实提示。

界面响应修复覆盖数据库重复初始化、播放期间的同步写锁等待、小型媒体库的同步全库读取，以及原图在界面线程解码。观看时长和位置在后台保存，使用累计快照重试，避免重复统计；退出时异步等待最后写入，持续争锁则保留本地恢复文件，下次播放时自动重试。

## 在哪里找日志

Windows 按 `Win + R`，粘贴 `%LOCALAPPDATA%\Lumen` 后回车。也可在“任务与诊断”顶部点击“打开日志目录”或“复制日志路径”，这里显示当前实际数据目录。

- `diagnostics.log`：启动信息、后台任务失败、数据库保存失败等；每份最多 5 MiB，另保留最近 3 份。
- `ui-hangs.log`：界面心跳超过 3 秒未响应时，后台自动记录界面线程及其他 Python 线程堆栈；每份最多约 4 MiB，另保留最近 2 份。没有触发卡顿时不一定存在。
- `ui-native-hangs.log`：原生调用阻止 Python 监控运行时，由 CPython 的 C 级监控在约 5 秒后补充堆栈；每次停滞最多记录一次，并保留最近 2 份轮转文件。
- `playback-pending.json`：退出时数据库持续被占用才可能生成，用于恢复未写完的观看记录。不要手工删除该文件。

如果使用 `--data-dir` 或 `LUMEN_DATA_DIR` 指定过数据目录，以上文件在该目录内。仍然无响应时，可以直接从资源管理器取日志，不必等窗口恢复。排查所需的是发生问题时的 `diagnostics.log`、`ui-hangs.log`、`ui-native-hangs.log`（存在时）和卡住前的操作；不需要提供媒体库数据库或视频。

锁竞争和大图读取的回归使用真实 SQLite 写锁和延迟解码，确认等待期间 Qt 事件循环继续运行。它们不能替代用户设备上的驱动、网络磁盘与原生播放器验证；仍需用日志定位残余的实际卡顿。
